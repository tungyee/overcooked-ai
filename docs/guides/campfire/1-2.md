## 菜谱 / 订单

- 原味棉花糖饼干：烤棉花糖 + 全麦饼干。
- 巧克力棉花糖饼干：烤棉花糖 + 全麦饼干 + 切好的巧克力。
- 香蕉棉花糖饼干（Banana S'more）：烤棉花糖 + 全麦饼干 + 切好的香蕉。
- 工序：棉花糖烤熟，巧克力/香蕉先切；装盘 = 全麦饼干 + 烤棉花糖 + 对应配料。

## 关卡机制 / 地形

- 延续 1-1 的营火机制，仍是「砍柴 → 喂火 → 烤棉花糖」循环，无移动平台等复杂机关。
- 比 1-1 多一种配料（香蕉），配料切板与营火之间要走动，容易在取料时浪费时间。

## 打法与分工（2P）

- 玩家：砍柴喂火 + 把棉花糖铺满营火，保持火力。
- 你：按订单切巧克力/香蕉，接烤熟的棉花糖装盘、送餐。
- 节奏：营火尽量满负荷烤棉花糖；配料切在营火烤制期间完成，避免等营火时干站着。
- 可先囤几份切好的巧克力/香蕉备用，订单轮换时直接拿。

## 陷阱与注意

- 火灭风险同 1-1；本关配料种类增加，容易「切错配料」装错盘，务必看订单。
- 香蕉/巧克力别一次切太多，切好的配料不用会被浪费（会占台面）。
