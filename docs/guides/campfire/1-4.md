## 菜谱 / 订单

- 全部是**薄煎饼（Pancake）**：面粉 + 鸡蛋进搅拌机搅成面糊，再倒进煎锅（skillet）煎熟。
- 常见轮换：原味薄煎饼 / 巧克力薄煎饼（面糊加巧克力）/ 蓝莓薄煎饼（面糊加蓝莓）。
- 工序：面粉 + 鸡蛋 → 搅拌 → 煎锅煎熟 → 装盘出餐。

## 关卡机制 / 地形

- **上下两条移动台面**：顶部（搅拌机所在）与底部（煎锅/灶台所在）的台面会**每隔 20~30 秒左右平移一次**，站台位置和取料/放料点会周期性错位。
- 搅拌机和煎锅分居两层台面，面粉/鸡蛋/巧克力/蓝莓等料点分布在台面之间。
- 无营火/背包，是纯「搅拌 → 煎」节奏关，但台面平移让走位和投掷时机变关键。

## 打法与分工（2P）

- 玩家：负责搅拌面糊——取面粉/鸡蛋/配料进搅拌机，把搅好的面糊送到煎锅侧。
- 你：负责煎锅——接面糊下锅、盯熟度、盛盘出餐。
- 节奏：搅拌机和煎锅都别空；台面平移前把半成品/面糊放到「下一轮仍够得到」的位置，或直接投掷跨台。
- 据 bilibili 玩家经验：本关只有两种菜单组合，是纯节奏关，**就算做错也先继续上菜，不要停手**——一旦停手节奏就断了。

## 陷阱与注意

- **台面平移**：料放在台面上会被带偏，放料/取料要抓平移间隙，别把半成品落在两层台面之间的缝里。
- 煎锅容易糊：面糊下锅后要盯火，熟了立刻盛盘。
- 别一次囤太多生面糊在台面，平移时容易丢。
