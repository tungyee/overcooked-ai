## 菜谱 / 订单

- **早餐拼盘（Breakfast Plate）**：从 香肠 / 培根 / 焗豆 / 鸡蛋 中取 2~4 种组合，装进煎锅煎熟后装盘出餐。本关所有订单都是**只有 2 种食材**的简单拼盘。
- 工序：香肠/培根需先切，焗豆（罐装）与鸡蛋直接放；组合后进煎锅煎熟。

## 关卡机制 / 地形

- **灶台和洗碗池在高台上**（elevated platform），食材箱与砧板在低处，需要把切好的料拿到高台煎、脏盘拿回低处洗，形成上下两层走位。
- 没有营火/背包，是「切 → 煎 → 出餐 → 洗碗」的常规节奏关，但上下层动线拉长。

## 打法与分工（2P）

- P1（队友）：负责低处切香肠/培根，把切好的料送上高台煎锅侧。
- P2（你 / AI）：负责高台煎锅——接料下锅、盯熟度、盛盘出餐，并把脏盘送回低处给 P1 洗。
- 节奏：煎锅别空；双料拼盘很快，重点在「切料不断供」和「脏盘及时回收」；两人上下层分工明确，避免都挤在楼梯/高台口。

## 陷阱与注意

- **上下层动线**：楼梯口是瓶颈，两人错峰上下，别互相挡。
- 切料跟不上会让煎锅空转；脏盘不及时洗会占满台面。
- 双料拼盘做错（配错料）会直接浪费一单，看准订单再装。
