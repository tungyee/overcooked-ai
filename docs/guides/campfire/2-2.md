## 菜谱 / 订单

- **早餐拼盘**：香肠 / 培根 / 焗豆 / 鸡蛋 的组合，本关会出现 **3 种甚至 4 种食材**的复杂拼盘。
- 工序：香肠/培根先切，焗豆、鸡蛋直接放；按订单把 2~4 种料一起进煎锅煎熟装盘。

## 关卡机制 / 地形

- **背包机制**：香肠和培根（肉类）装在被背着的背包里，需另一名玩家从对方背包取料，被取者站定。
- 厨房**较大、厨具分散**，取料/切/煎/出餐之间的路程长，容易出现断供。

## 打法与分工（2P）

- 玩家：背肉料背包，负责被取料 + 切肉 + 送切好的肉到煎锅。
- 你：从玩家背包取香肠/培根、组合焗豆/鸡蛋、下煎锅、盯熟度、盛盘出餐。
- 节奏：复杂拼盘料多，**先确认订单要哪几种料再取**，避免漏放/多放；煎锅口别空，一人切一人煎形成流水线。
- 背包取料同样约定「站定取料」，别两人同时走动。

## 陷阱与注意

- 3~4 料拼盘最容易**漏放或放错一种料**，直接废单；下锅前逐项核对。
- 肉料全靠背包取，取料效率决定上限，别让「背包取不到」成为瓶颈。
- 厨具分散，来回别空手，顺手带下一单的料。
