## 菜谱 / 订单

- 全部是**棉花糖饼干（S'mores）**，但配料更复杂（可能轮换巧克力/香蕉/草莓/香蕉+草莓等组合）。
- 工序：棉花糖在营火烤熟；配料（巧克力/香蕉/草莓）先切；装盘 = 全麦饼干 + 烤棉花糖 + 配料。

## 关卡机制 / 地形

- **木柴和棉花糖只能从背包取**：本关的关键原料全走背包，被取者必须站定，是「背包取料」强度最高的一关。
- 厨房**两侧各有 2 个营火**，两侧都要喂柴烤棉花糖，无法单侧包办。

## 打法与分工（2P）

- 玩家：背其中一种关键原料（木柴或棉花糖），负责喂火 + 烤一侧的棉花糖。
- 你：从玩家背包取料、切配料、烤另一侧、装盘出餐。
- 节奏：**开局先把木柴和棉花糖从两人背包里尽量囤到台面上**，减少后续来回取背包的次数；两侧营火都保持有火有货。
- 背包取料频繁，务必固定「站定取料」的配合，避免空转。

## 陷阱与注意

- 木柴/棉花糖取不到 = 直接断供，背包配合是本关胜负手。
- 两侧营火都要有人盯，单侧烤不过来会拉低出餐速度。
- 配料种类多，切料前先看订单，别切错。
