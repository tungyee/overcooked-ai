## 菜谱 / 订单

- **薄煎饼（Pancake）**：面粉 + 鸡蛋（可选加巧克力/蓝莓）→ 搅拌 → 煎锅煎熟。
- **蛋糕（Cake）**：面粉 + 鸡蛋 + 切好的蜂蜜 → 搅拌 → 烤箱烤熟；胡萝卜蛋糕再加切好的胡萝卜。
- 工序共性：面粉 + 鸡蛋 + 配料 → 搅拌 → 煎/烤。

## 关卡机制 / 地形

- **三块放食材和砧板的台面每 30 秒轮换平移**，取料点/切板位置周期性变动，走位要跟着台面节奏。
- 煎锅和烤箱分布在固定位置，搅拌机随台面移动。
- 蜂蜜、面粉、胡萝卜等料点分散，需按台面轮换顺序安排取料。

## 打法与分工（2P）

- 据 bilibili 玩家经验：
  - **左右两边各站一个小人**，保证两侧都有覆盖。
  - 开局先准备 **5 份蜂蜜 + 每边 5 份面粉**，基本够用；右边有空就切蜂蜜，左边注意切胡萝卜和送脏盘。
  - 漏做/做错时，**煎锅比蛋糕简单，偷做一两道薄煎饼补分**。
- 分工建议：P1 管搅拌 + 切料（蜂蜜/胡萝卜），P2 管煎锅/烤箱熟度 + 出餐 + 洗碗。
- 台面平移前把手头半成品放到「下一轮够得到」的固定台面。

## 陷阱与注意

- **台面平移丢料**：半成品别留在会移走的台面上，避免被带离或掉缝。
- 蛋糕流程长（面粉+鸡蛋+蜂蜜→搅拌→烤箱），是耗时瓶颈，烤箱要持续有货。
- 三星门槛高（1040），节奏不能断；用简单薄煎饼补单比硬凑蛋糕更稳。
