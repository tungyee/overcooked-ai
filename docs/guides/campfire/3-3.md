## 菜谱 / 订单

- 全是**棉花糖饼干（S'mores）**：烤棉花糖 + 全麦饼干 + 配料（巧克力/香蕉/草莓等按订单）。
- 工序：棉花糖在营火烤熟；配料先切；装盘出餐。

## 关卡机制 / 地形

- **4 个木柴炉（营火）**，火力全靠喂柴。
- **木柴和棉花糖都只能从背包取**：两个背包分别装木柴和棉花糖，被取者站定。
- 三星容易，但**解锁凯文 3 的分数门槛高**（双人 800），需要连续出单冲分。

## 打法与分工（2P）

- 据 bilibili 玩家经验：
  - 整关大约 **9 单就能过三星**；开局**先切棉花糖（其实是先备棉花糖），然后加木柴**，切配料严格按菜单走、不要瞎切。
  - 前中期紧凑一点、后期就轻松。
  - 开局从两个背包里**尽量多囤棉花糖和木柴到台面**，减少后续来回取背包的次数。
- 分工建议：玩家背木柴包、负责喂 4 个营火；你背棉花糖包、负责烤棉花糖 + 切配料 + 装盘出餐。
- 冲凯文 3 时（双人 800）：保持连续出单，别断连；剩余约 1 分钟开始盯菜单，能跳单/抢高分就抢。

## 陷阱与注意

- 火灭/断柴会直接拖慢出餐，喂火是第一优先级。
- 棉花糖/木柴取不到是最大瓶颈，站定取料要形成习惯。
- 切配料前先看菜单，切错配料 = 废单 + 断连。
