## 菜谱 / 订单

- **早餐拼盘**：香肠 / 培根 / 焗豆 / 鸡蛋 组合，进煎锅煎熟。
- 工序：香肠/培根先切，焗豆/鸡蛋直接放，按订单组合下锅。

## 关卡机制 / 地形

- **超长关卡 + 高分数要求**；玩家所在的平台会在**两个时间点漂走**，把人和半成品一起带离，打乱节奏。
- 平台漂走时料点/灶台会暂时够不到，需要靠投掷或等待平台回来。
- 这是本 DLC 公认最难的一关（综合能力 + 运气，看订单组合）。

## 打法与分工（2P）

- 据 bilibili 玩家经验：
  - 大致记住**地图漂走的时间点**，给自己留抢救食材的余地；**保证一个人一直切**，切菜不能停。
  - 出餐轮次参考：**第一轮做 3 道、第二/三轮各 2 道、最后一轮 2 道以上**；最容易乱的是第二、三轮，第四轮别忘洗盘子（下方会很忙）。
  - 闲时把菜**囤到左边**，防止平台漂走时没料可拿。
- 分工建议：玩家专司切料 + 喂煎锅，你管煎锅熟度、出餐、洗碗；平台漂走前先把手头半成品放到安全位置。

## 陷阱与注意

- **平台漂走**：正在煎的菜、切到一半的料可能被带离灶台/砧板，漂走前要收尾或投掷到固定台。
- 高门槛 + 长流程，容错低；订单组合看运气，遇到差单也要维持出餐别停。
- 别忘洗碗，后期脏盘堆积会拖垮最后一轮。
