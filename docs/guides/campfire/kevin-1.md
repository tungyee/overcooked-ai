## 菜谱 / 订单

凯文关沿用主线凯文关的**蒸菜**食谱，两类成品混合出现：

- 蒸包子/蒸饺：面粉 + 底料（肉排/虾肉/胡萝卜）→ 切底料 + 搅拌机搅成生包子 → 蒸笼蒸熟。
- 清蒸鱼：鱼切好后直接上蒸笼蒸熟（不需要搅拌机）。

## 关卡机制 / 地形

- 厨房被分成**四个象限**，靠**两个传送门**连通，各象限放不同厨具（搅拌机/砧板/蒸笼/出餐口等）。
- 没有营火/背包；难点在传送门走位和四象限分工，容易「走错门」绕远路。

## 打法与分工（2P）

- 按传送门就近分两侧：一侧负责切底料 + 搅拌成生包子；另一侧负责切鱼 + 蒸 + 出餐，双方靠传送门/投掷传半成品。
- 节奏：据 bilibili 玩家经验，**一次做 4 单一起做，做两轮共 8 单即可过关**；宁慢勿抢，别同时抢两道菜导致走错门。
- 蒸包子是最慢的瓶颈，搅拌机和蒸笼都要保持不空；清蒸鱼在蒸包等待时插空补上维持连击。

## 陷阱与注意

- **走错门**：四象限 + 传送门，跑错方向会绕大圈，务必先认准「搅拌→蒸→出餐」的传送门路径。
- 投掷传半成品时落点要准，别让生包子/鱼掉地上。
- 记得洗盘子，脏盘堆积会拖慢出餐节奏。
