## 菜谱 / 订单

沿用凯文关的**蒸菜**食谱：

- 蒸包子/蒸饺：面粉 + 底料（肉排/虾肉/胡萝卜）→ 切底料 + 搅拌机搅成生包子 → 蒸笼蒸熟。
- 清蒸鱼：鱼切好后直接上蒸笼蒸熟。

## 关卡机制 / 地形

- **两套台面靠按钮切换**：一套台面有 3 块砧板 + 食材，另一套有盘子、搅拌机、蒸笼。按键在两套布局之间切换，相当于「工作台会轮换消失/出现」。

## 打法与分工（2P）

- 据 bilibili 玩家经验：
  - 一次大概切 **6 单左右**一起做，比较省事，不用来回换台面。
  - **多准备一条鱼**备用；一个负责洗盘子、一个负责看蒸笼/搅拌，很容易过。
  - 最后有清蒸鱼就做鱼，**不要再去搅拌拼人品**（蒸鱼流程短，更容易补单）。
- 分工建议：一人管切料/搅拌，一人管蒸笼/出餐/洗碗；台面切换前把手头半成品收好。

## 陷阱与注意

- **台面切换时机**：切换会把砧板/搅拌/蒸笼整体换走，正在进行的半成品要提前收好，别切到一半被切走。
- 别硬凑带馅蒸包（搅拌耗时、还看搅拌机是否可用），最后阶段优先用清蒸鱼补单。
