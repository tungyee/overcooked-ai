## 菜谱 / 订单

沿用凯文关的**蒸菜**食谱：

- 蒸包子/蒸饺：面粉 + 底料（肉排/虾肉/胡萝卜）→ 切底料 + 搅拌 → 蒸笼蒸熟。
- 清蒸鱼：鱼切好后直接上蒸笼蒸熟。

## 关卡机制 / 地形

- **三条传送带占据厨房大部分面积，所有食材从传送带上输出**，捡料位置随传送带流动。
- 无营火/背包；难点在传送带取料 + 高分数门槛（1060）。

## 打法与分工（2P）

- 据 bilibili 玩家经验：
  - **一次做 3 单，做 3 轮**时间刚好不紧张。
  - 切菜的**尽量别停**，传菜（投掷/走位）过程小心些。
  - **最后一单跳单**（利用订单顺序抢分）；剩约 1 分钟就开始盯菜单，手速快的可无视。
- 分工建议：P1 管传送带捡料 + 切底料/鱼 + 搅拌；P2 管蒸笼、出餐、洗碗。
- 传送带上的料会流走，看到就捡，别等末端。

## 陷阱与注意

- **传送带漏料**：食材流走即损失，捡料要及时；投掷半成品别扔回传送带。
- 蒸包子流程长，搅拌机/蒸笼保持不空；最后阶段用清蒸鱼补单更稳。
- 高门槛下容错低，投掷/传菜失误要尽量少。
