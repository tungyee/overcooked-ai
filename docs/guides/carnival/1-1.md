## 菜谱 / 订单

- 本关是 DLC 开场关，菜单为嘉年华快餐：汉堡、热狗为主，部分订单是「套餐（托盘）＝主菜 + 配菜 + 饮料」。
- 汉堡：面包胚 + 煎熟的肉饼（可选奶酪/生菜/番茄）。
- 热狗：面包胚 + 煮熟的香肠，可用酱汁机加番茄酱/芥末酱。
- 套餐：把主菜（汉堡/热狗）＋ 配菜（洋葱圈/奶酪片/薯条）＋ 饮料放在同一个托盘上出餐。
- 配菜：洋葱圈（洋葱切碎 → 炸锅）、薯条（土豆切碎 → 炸锅）、奶酪片（直接取）。
- 具体每单组合以实时快照的菜谱/订单为准，AI 不用死记。

## 关卡机制 / 地形

- 首次引入**大炮**：一名厨师站进炮口，另一名厨师按按钮把 TA 发射到另一端；是跨区/跨障碍的核心运输方式。
- 首次引入**托盘（套餐）**：套餐必须用托盘端着一起出，托盘单次可载主菜、配菜、饮料三样。
- **饮料机**：直接取对应颜色口味的软饮，口味可通过按钮切换，无需切/煎/煮。
- **酱汁机**：给热狗浇番茄酱/芥末酱，同样无需额外加工。
- 本关有脏盘需回收洗碗（双人四星视频特别提到「提升点在洗盘子」）。

## 打法与分工（2P）

- 玩家：负责主菜——煎肉饼 / 煮香肠，顺带看火别糊。
- 你：负责组装——取面包胚、打饮料、端托盘、凑齐套餐出餐；同时盯着脏盘回收洗碗。
- 流程：先铺开主菜的生产线（煎肉饼/煮肠最慢），期间把饮料、配菜、托盘备好，主菜一熟立刻组装成套餐出餐；托盘别空等。
- 有套餐订单时优先凑套餐（单份分数高），散单见缝插针。

## 陷阱与注意

- 大炮要两人配合：被发射的人站进炮口，操作的人按按钮，别站错位置干等。
- 套餐漏了饮料/配菜会导致出不了餐，凑齐三样再端上。
- 脏盘堆积会占台面，尽早回收洗碗。
