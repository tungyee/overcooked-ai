## 菜谱 / 订单

- 嘉年华快餐轮换：汉堡、热狗为主，穿插套餐（托盘＝主菜 + 配菜 + 饮料）。
- 汉堡：面包胚 + 煎熟肉饼；热狗：面包胚 + 煮熟香肠（可加酱）。
- 套餐配菜：洋葱圈（切洋葱 → 炸锅）、薯条（切土豆 → 炸锅）、奶酪片（直接取）；饮料从饮料机取。
- 订单组合以实时快照为准。

- 大炮、托盘、饮料机、酱汁机均为本 DLC 通用机制（见 1-1）。

## 打法与分工（2P）

- 通用打法推断（未找到本关公开 2P 攻略）：
  - P1（队友）：主攻主菜（煎肉饼/煮香肠），保证主菜不断供。
  - P2（你 / AI）：组装套餐（面包胚、饮料、配菜、托盘）并出餐，兼顾洗碗。
- 若本关有移动平台，尽量让「成品」走平台运输、人少跑动；AI 上平台前先确认目的地不会挡路。

## 陷阱与注意

- 主菜糊锅/煮过是断供主因，盯火。
- 套餐漏件出不了餐；移动平台上掉落食材会丢失。
