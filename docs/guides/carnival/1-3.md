## 菜谱 / 订单

- 嘉年华快餐：汉堡、热狗、套餐（托盘＝主菜 + 配菜 + 饮料）。
- 汉堡＝面包胚 + 煎熟肉饼；热狗＝面包胚 + 煮熟香肠（可加酱）；套餐配菜洋葱圈/薯条/奶酪片，饮料走饮料机。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 本关对**扔菜（投掷）**要求高：两边需要互相投掷食材/成品，跨区交接多。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468，原为单人思路，双人可拆成两边）：
  - 「两单做或者 1+1」：成对制作订单，两边各负责半套，互相投掷补齐。
  - 节奏要好，**扔菜要准**，比较吃手速。
- 2P 分工：
  - 玩家：负责主菜加工（煎肉饼/煮肠），做好后投给你。
  - 你：负责组装与出餐，把面包胚/饮料/托盘备齐，接住玩家投来的主菜装盘。
- 两边相距较远时用**投掷**代替跑动，能显著省时。

## 陷阱与注意

- 投掷落地位置不好会掉件，宁可走近一步再投。
- 主菜断供/糊锅风险同前；套餐漏件出不了餐。
