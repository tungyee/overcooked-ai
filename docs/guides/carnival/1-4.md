## 菜谱 / 订单

- 世界 1 收尾关，菜单仍是嘉年华快餐轮换：汉堡、热狗、套餐（托盘＝主菜 + 配菜 + 饮料）。
- 汉堡＝面包胚 + 煎熟肉饼；热狗＝面包胚 + 煮熟香肠（可加酱）。
- 套餐配菜：洋葱圈/奶酪片/薯条；饮料从饮料机取。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 本关时长最短（2:30）且最低单数较高（单人 10 单），节奏紧凑。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 通用打法推断（未找到本关公开 2P 攻略）：
  - 玩家：主攻主菜（煎肉饼/煮香肠），不停火、不停手。
  - 你：组装套餐 + 出餐 + 洗碗，把饮料/配菜/托盘提前铺在出餐动线附近。
- 短关卡容错低：开局就要把主菜生产线跑起来，别等订单刷新才动手。

## 陷阱与注意

- 时间短，主菜糊一次基本断一单，盯火优先。
- 套餐漏件/脏盘堆积都会拖慢节奏。
