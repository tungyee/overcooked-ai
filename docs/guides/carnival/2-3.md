## 菜谱 / 订单

- 嘉年华快餐轮换：汉堡、热狗、套餐（托盘＝主菜 + 配菜 + 饮料）。
- 汉堡＝面包胚 + 煎熟肉饼；热狗＝面包胚 + 煮熟香肠（可加酱）。
- 套餐配菜：洋葱圈/奶酪片/薯条；饮料从饮料机取。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 本关被多位攻略作者点名「考验技术」：难点在速度、准度、稳定度。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468）：
  - 「一个切菜一个配菜，一道或两道做，形成流水线」——双人天然适配。
  - 难点是速度、准度、稳定度，不要失误。
- 2P 分工：
  - P1（队友）：专职切菜/主菜加工，形成稳定上游。
  - P2（你 / AI）：专职配菜/组装/出餐，接住上游半成品形成流水线。
- 追求按顺序连击（combo）能同时冲星和解锁凯文 2。

## 陷阱与注意

- 流水线任何一环停手都会卡整条线，宁可节奏均匀也不要忽快忽慢。
- 连续按顺序提交容易断 combo，注意别做错顺序。
