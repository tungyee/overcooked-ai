## 菜谱 / 订单

- 嘉年华快餐轮换：汉堡、热狗、套餐（托盘＝主菜 + 配菜 + 饮料）。
- 汉堡＝面包胚 + 煎熟肉饼；热狗＝面包胚 + 煮熟香肠（可加酱）。
- 套餐配菜：洋葱圈/奶酪片/薯条；饮料从饮料机取。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 本关大炮可用可不用（攻略作者表示「我没用过大炮」），说明有常规路径可达各站点。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468）：
  - 「切菜不能停，可以三单做也可以 2+1，自己掌握节奏」。
- 2P 分工：
  - P1（队友）：专职切菜，保证上游不断。
  - P2（你 / AI）：主菜加工 + 组装 + 出餐，按「三单一批」或「2+1」节奏凑单。
- 长时间关卡（4:30），重点是稳定的持续产出而非爆发。

## 陷阱与注意

- 切菜停手会让整条线饿死，保持均匀节奏。
- 门槛高（单人 1420），任何糊锅/漏件都会拉低总分，减少失误比提速更重要。
