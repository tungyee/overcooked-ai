## 菜谱 / 订单

- 本关**饮料（汽水）需求量大**：套餐＝主菜 + 配菜 + 饮料，饮料是高频件。
- 汉堡＝面包胚 + 煎熟肉饼；热狗＝面包胚 + 煮熟香肠（可加酱）。
- 套餐配菜：洋葱圈/奶酪片/薯条；饮料从饮料机取（可提前囤）。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 本关有**掉落/坠崖风险**（攻略明确「小心掉下去」），移动平台或边缘区域需谨慎走位。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468）：
  - 「两单做的速度比较舒服，汽水可以屯，不屯也可以直接用盘子接，很吃手速」。
- 2P 分工：
  - 玩家：主菜加工（煎肉饼/煮香肠）。
  - 你：**提前囤汽水**、组装套餐、出餐；饮料机附近来回频繁。
- 汽水可囤：闲时多接几杯放在台面，忙时直接取用省跑动。

## 陷阱与注意

- 走位不当会掉下平台，掉一件等于废一单，宁可绕路也不贴边。
- 汽水是高频需求，别等订单来了才去接。
