## 菜谱 / 订单

- 本关以**热狗**为主：左边煮菜（煮香肠），右边切菜（切香肠段/备面包胚）。
- 热狗＝面包胚 + 煮熟香肠；酱汁机加番茄酱/芥末酱。
- 攻略提示「最后有两个单肠子」——后期订单常是热狗，要提前备干净盘子和面包胚、面包配酱。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮、托盘、饮料机、酱汁机通用（见 1-1）。
- 布局分左右职能：左边煮、右边切，中间需互相投掷/走位交接。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468）：
  - 「左边煮菜，右边切菜」。
  - 「运气好最后两个单是肠子就舒服；如果没有，要提前给干净盘子、面包拿个酱，以防万一」。
- 2P 分工：
  - P1（队友）：负责煮（香肠），守住煮锅不断货。
  - P2（你 / AI）：负责切（香肠段/备面包胚），并提前备好干净盘子和蘸好酱的面包胚，随时组装热狗出餐。
- 后期订单偏热狗时，提前囤熟肠/面包/酱能稳收尾。

## 陷阱与注意

- 煮肠糊锅/煮过是主风险；提前备件比临场赶工稳。
- 酱汁机口味要按订单切换，别默认同一种酱。
