## 菜谱 / 订单

- 本关是**综合关**，几乎涵盖 DLC 全部工序：煮（热狗香肠）、切（面包胚/洋葱）、搅拌（甜甜圈面团）、炸（甜甜圈/洋葱圈）。
- 热狗：面包胚 + 煮熟香肠（可加酱）。
- 甜甜圈：面团（鸡蛋 + 面粉进搅拌机）→ 炸锅油炸。
- 洋葱圈：切碎的洋葱 → 炸锅。
- 汉堡：面包胚 + 煎熟肉饼（视订单轮换）。
- 具体每单以实时快照为准。

## 关卡机制 / 地形

- 大炮是核心运输手段，本关要「少飞」：飞行次数越少越好，减少卡炮口/落点失误。
- 搅拌机（做甜甜圈面团）、炸锅、煮锅并存，站点多、动线长。
- 攻略提示「搅拌机最好放切板中间，方便扔鸡蛋面粉」——涉及投掷原料进搅拌机。
- 未找到逐帧布局，站点位置以游戏内快照为准。

## 打法与分工（2P）

- 打法要点（来源 av67680468，较详细）：
  - 「理论上 442 这样做最舒服，少飞是关键」——按节奏分批做单。
  - 左边：「保持煮一个肠子就要放一个面包去切，洋葱看情况；碟子加任意东西就可以给酱，省时间」。
  - 右边：「搅拌机放切板中间，方便扔鸡蛋面粉；至少做 3 单；炸锅简单」。
  - 「一起切可以加速，减少失误，减少飞行；上菜走直线」。
- 2P 分工：
  - 玩家：守左半边——煮香肠、切面包胚、洋葱，给酱装热狗。
  - 你：守右半边——鸡蛋面粉进搅拌机做面团、炸甜甜圈/洋葱圈，组装套餐出餐。
- 上菜走直线，别误入传送门/大炮，减少飞行。

## 陷阱与注意

- 大炮卡炮口/落点偏会浪费时间：要在**大炮前方**进入，别从侧面挤进去。
- 综合关动线长，规划好「谁在哪半边」别来回横穿。
- 甜甜圈面团依赖搅拌机，鸡蛋/面粉投掷要准。
