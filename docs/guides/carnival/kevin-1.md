## 打法与分工（2P）

- 打法要点（来源 av67680468）：「生做，节奏不要乱」——即不追求花哨操作，按稳定节奏一单一单做。
- 通用打法推断：
  - 玩家和你各自守住主菜/组装一边，保持均匀节奏，避免贪多抢两单。
  - 有套餐订单时先凑齐主菜 + 配菜 + 饮料再上托盘。

## 陷阱与注意

- 已知 BUG：有时上菜后没加分、菜「凭空消失」——对着上菜口再点一下，菜会重新出现（来源 av67680468）。出餐后留意计分，没加分就补一次交互。
- 节奏乱是最大风险，宁慢勿乱。
