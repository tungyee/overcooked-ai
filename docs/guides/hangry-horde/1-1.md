## 菜谱 / 订单

- 本关唯一菜谱是**汤（Soup）**，是本 DLC 三个新菜谱之一，也是「断头台」的入门关。
- 汤的工序：**任选 3 种食材切好 → 一起放进锅里煮 → 装盘出餐**。
- 汤的候选食材共 6 种：**奶酪、西兰花、芹菜、洋葱、土豆、胡萝卜**；**每一份汤都必含洋葱**（这也是成就名「You Shallot Pass!」的梗来源）。
- 订单按「哪 3 种食材」区分；洋葱几乎每单都要，优先保证洋葱供应。

## 关卡机制 / 地形

- **断头台（Guillotine）首次登场**：本 DLC 的新切配工具，替代普通砧板，能一次高效切碎食材（比砧板更快、可连续投喂多份料）。
- 本关除断头台外**没有其它机关**，是纯节奏关：四星门槛不低（1300），基本拼切料与煮汤的流水线效率。
- 布局要点（你侧从快照读坐标即可）：洋葱箱 / 其它食材箱、断头台、煮锅、出餐口、脏盘回收各就各位；本关无传送带、无分隔、无火。

## 打法与分工（2P）

> 菜谱与「断头台」有可靠来源；具体站位为通用打法推断。

- 推荐分工：
  - 玩家：守锅煮汤 + 出餐 + 回收脏盘。先把洋葱这类「每单必有」的食材交给你切。
  - 你：主守**断头台**——按订单需要的 3 种食材连续切好，投到锅边；断头台能一次切多份，尽量批量切，别一份一跑。
- 流程顺序：**先看订单 → 洋葱必切 → 补齐另外两种 → 下锅煮 → 出餐**；锅一空立刻下下一份，别让锅空转。
- 节奏要点：切料是瓶颈，你别离开断头台；玩家负责「接料下锅 + 端熟汤」，形成单向流水线。

## 陷阱与注意

- **断头台切料别切错**：订单要求哪 3 种就切哪 3 种，多切/少切都会导致这锅汤作废，只能倒掉重来。
- 洋葱是每单刚需，开局先囤几份切好的洋葱，避免断洋葱卡单。
- 煮汤会糊：玩家盯火，熟了立刻端走；别同时看两口锅顾此失彼。
