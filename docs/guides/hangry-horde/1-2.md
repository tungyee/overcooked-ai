## 菜谱 / 订单

- 本关菜谱是**烤肉晚宴（Roast Dinner）**，本 DLC 三个新菜谱之一。
- 工序：**烤牛肉块（roast）或鸡（两者都无需切） + 切好的土豆 + 切好的胡萝卜 → 一起进烤箱（熔炉）烤**。部分订单还会加西兰花。
- 每份烤肉晚宴**必含一种肉 + 土豆 + 胡萝卜**，肉不用切，土豆/胡萝卜要切（西兰花选配）。

## 关卡机制 / 地形

- **熔炉（Furnace）/ 煤（Coal）首次登场**：本关的烤箱是烧煤的熔炉，**必须持续加煤才能保持烘烤**；煤烧完火会灭、温度下降，菜品烤不熟甚至作废。
- 本关除「熔炉加煤」外没有其它机关；真正的难点是**同时盯火 + 盯煤 + 切配**。
- 布局要点：煤桶通常在熔炉附近，出餐口 / 脏盘回收按快照读取；本关无移动平台、无分隔。

## 打法与分工（2P）

> 菜谱与「熔炉加煤」有可靠来源；具体站位为通用打法推断。

- 推荐分工：
  - P1（队友）：主守**熔炉 + 煤**——持续往熔炉里铲煤、把肉+配菜下炉、盯烤熟出餐。
  - P2（你 / AI）：主守**砧板切配**——切土豆、切胡萝卜（西兰花选配），并把肉块/鸡递给 P1；空闲时帮铲煤。
- 流程顺序：**开局先确认煤桶位置 → 边切配边给熔炉上煤 → 肉 + 土豆 + 胡萝卜凑齐下炉 → 烤熟出餐**；熔炉一空立刻补下一炉料。
- 节奏要点：煤是隐藏的时间成本，P1 要养成「路过就铲一铲」的习惯，别等火灭了再救。

## 陷阱与注意

- **忘记加煤**是最大翻车点：火灭后烤炉停摆，熟菜进度归零甚至烧糊，四星基本要重开（bilibili 攻略标题直点「记得加炭」）。
- 肉不用切、别把肉拿去砧板多此一举；土豆和胡萝卜才需要切。
- 熔炉烤久了会糊，P1 盯熟；P2 切配跟不上会让炉子空转，两边要保持同节奏。
