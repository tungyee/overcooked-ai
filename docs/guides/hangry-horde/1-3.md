## 菜谱 / 订单

- 继续做**烤肉晚宴（Roast Dinner）**：烤牛肉块或鸡（无需切）+ 切好的土豆 + 切好的胡萝卜（部分订单加西兰花），进熔炉烤。
- 延续 1-2 的「加煤」机制，本关在此基础上叠加大型机关（见下）。

## 关卡机制 / 地形

- **中央开关移动平台**：厨房中间有一个开关，用来移动承载食材箱与砧板/工位的平台；**同一时间只有半边厨房能取到料、能切配**，需要来回切开关。
- 配合熔炉加煤，本关是「切配半场受限 + 盯火 + 盯煤」的三重节奏关。
- 布局要点：食材与切配工位会随平台移动，你侧**不要缓存站点坐标**，每拍从快照重读当前可用工位；熔炉 / 出餐口位置相对固定。

## 打法与分工（2P）

> 机关描述有可靠来源；具体分工为通用打法推断。

- 推荐分工：
  - 玩家：守**熔炉 + 煤 + 出餐**（相对固定的一侧）。
  - 你：守**切配**，并负责按需切中央开关，把带料/带砧板的那半面移到自己或玩家这边。
- 流程顺序：**开局确认哪半面当前有料 → 切齐土豆/胡萝卜 → 移动平台把料送到熔炉侧 → 加煤下炉 → 出餐**。
- 节奏要点：平台切换有硬性时间成本，**批量切料、一次搬够**，减少来回切开关的次数；切配侧别囤料过头，否则换面时料拿不到。

## 陷阱与注意

- 平台切换时机错会导致「有料没砧板 / 有砧板没料」，两人同时卡在错误半面。
- 熔炉仍需加煤，别被机关分心后忘了煤，火灭整炉作废。
- 烤肉晚宴食材多（肉 + 2~3 配菜），漏一种就废单，出餐前逐项核对。
