## 菜谱 / 订单

- 本关菜谱是**卷饼（Burrito / Wrap）**，复用本体菜谱：**玉米烙饼 + 煮熟的米饭 + 切好并煎熟的肉排 / 鸡 / 蘑菇**。
- 工序：米煮成饭；肉排/鸡/蘑菇切好 → 煎熟；最后用烙饼包「熟饭 + 熟馅」装盘出餐。
- 烙饼和米饭都可提前备好，属于「能囤料」的菜谱，适合本关的移动平台布局。

## 关卡机制 / 地形

- **两侧分隔 + 中央移动平台**：厨房分两半，中间台面只能靠一块**木平台**通行，两侧的**拉杆（levers）移动这块平台**。
- 一侧偏「煮饭 / 取烙饼 / 囤料」，另一侧偏「切馅 / 煎馅 / 出餐」，投掷可以跨中间台面传递。
- 布局要点：AI 侧按快照识别「米箱 / 烙饼箱 / 煎锅 / 出餐口」分属哪侧；平台位置会变，别缓存通行路线。

## 打法与分工（2P）

> 机关与菜谱有可靠来源；具体分工为通用打法推断。

- 推荐分工：
  - P1（队友）：守**煮饭 + 烙饼侧**——煮饭、取烙饼、囤好半成品后投给对侧（Game Craves 提示：右侧角色囤米和烙饼，分数就很容易拿）。
  - P2（你 / AI）：守**切馅 + 煎馅 + 包卷出餐侧**——切肉排/鸡/蘑菇、煎熟、接饭接烙饼包卷。
- 流程顺序：**开局 P1 先煮饭 + 囤烙饼，P2 切煎馅料；饭熟后 P1 把饭和烙饼投过去，P2 包卷出餐**。
- 节奏要点：烙饼和熟饭可提前大量囤，跨侧传递靠**投掷**，比走移动平台省时间；平台拉杆谁顺路谁拉，别两人都去抢。

## 陷阱与注意

- 移动平台只有一块，两人同时要过会互相卡；约定「谁需要过谁拉杆」，错峰通行。
- 卷饼要「熟饭 + 熟馅」双熟：馅没煎熟或饭没煮好就包会废单。
- 烙饼包卷需要干净盘，脏盘回收路线可能跨平台，别让脏盘堆积断供。
