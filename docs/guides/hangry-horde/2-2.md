## 菜谱 / 订单

- 本关菜谱是**水果派（Fruit Pie）**，本 DLC 三个新菜谱之一。
- 工序：**面粉 + 鸡蛋 + 1~2 种切好的水果（樱桃 / 苹果 / 葡萄）→ 进搅拌机搅成派坯 → 进烤箱（熔炉）烘烤**。
- 水果要切、面粉和鸡蛋不用切；订单按「哪 1~2 种水果」区分。

## 关卡机制 / 地形

- **四象限布局 + 断头台 + 吊桥**：厨房被分成四块，食材与工位分散在各象限；切配用**断头台**；两侧靠**拉杆驱动的木平台（吊桥）**连接。
- 水果派工序跨象限（面粉/蛋在一边、水果在另一边、搅拌机和烤箱又在别处），是本关最大难点。
- 布局要点：AI 侧别缓存坐标，四象限 + 吊桥意味着「料从哪来、搅拌机/烤箱在哪、怎么跨区」都要每拍重读；吊桥位置可变。

## 打法与分工（2P）

> 机关与菜谱有可靠来源；具体分工为通用打法推断。

- 推荐分工：
  - P1（队友）：守**搅拌机 + 烤箱（熔炉）侧**——接面粉/蛋/切好的水果搅成派坯、加煤烤派、出餐。
  - P2（你 / AI）：守**断头台切水果侧**——把樱桃/苹果/葡萄切好，与面粉/蛋一起投过吊桥给 P1。
- 流程顺序：**开局各自认领象限 → P2 切水果、P1 备面粉蛋 → 凑齐搅派坯 → 下炉烤 → 出餐**；搅拌机与烤箱都不要空。
- 节奏要点：吊桥通行有成本，**半成品用投掷跨桥**；断头台批量切水果，减少来回过桥次数。

## 陷阱与注意

- 四象限容易走错区，端着半成品跑错桥是大坑；过桥前先确认目标工位在哪边。
- 水果派 3 步（切水果 → 搅拌 → 烤），搅拌机或烤箱任一空转都会拖慢全队。
- 烤箱仍是熔炉，别忘加煤；派烤糊只能倒掉重做。
