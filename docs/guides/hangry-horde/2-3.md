## 菜谱 / 订单

- 继续做**水果派（Fruit Pie）**：面粉 + 鸡蛋 + 1~2 种切好的水果（樱桃/苹果/葡萄）→ 搅拌机 → 烤箱（熔炉）烘烤。
- 延续 2-2 的工序，本关为世界 2 收尾关，节奏与机关更紧。

## 关卡机制 / 地形

- 沿用**断头台 + 熔炉（加煤）**两套核心机制；具体布局机关公开攻略描述不完整（见「来源」）。
- bilibili 高分攻略的关键提示是「**开局不倒煤**」——即开局先集中切配/搅拌，等第一炉真正要烤时再开始持续供煤，避免开局被「铲煤」占用节奏。
- 布局要点：你侧按快照重读断头台 / 搅拌机 / 熔炉 / 出餐口位置，本关同样别缓存坐标。

## 打法与分工（2P）

> 菜谱与「开局不倒煤」提示有可靠来源；具体站位为通用打法推断。

- 推荐分工：
  - 玩家：守**搅拌机 + 熔炉**——接料搅派坯、按需加煤、烤派出餐。
  - 你：守**断头台切水果 + 备面粉蛋**——批量切水果，把半成品投给玩家。
- 流程顺序：**开局先切水果 + 备面粉蛋，不急着铲煤 → 第一炉料备齐再下炉、这时开始规律供煤 → 烤熟出餐循环**。
- 节奏要点：煤只在「炉里有货」时才必须供；别在开局空炉时无意义铲煤占用双手。

## 陷阱与注意

- 水果派 3 步链任一环节断供（没切好的水果 / 搅拌机空 / 烤箱空）都会拖累连击。
- 熔炉加煤节奏要稳：供早了浪费动作，供晚了火灭烤不熟。
- 多份派一起下炉可摊薄加煤成本，但别囤过头烤糊。
