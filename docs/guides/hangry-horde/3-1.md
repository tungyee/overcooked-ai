## 打法与分工（2P）

> 菜谱为推断（依据成就名 Wrap Artist），打法为通用推断，请以实机快照为准。

- 推荐分工：
  - P1（队友）：守**煮饭 + 烙饼 + 出餐**——煮饭、取烙饼、包卷出餐。
  - P2（你 / AI）：守**切馅 + 煎馅**——肉排/鸡/蘑菇切好煎熟，投给 P1。
- 流程顺序：先煮饭、囤烙饼，同时切煎馅料；熟饭 + 熟馅 + 烙饼凑齐即包卷出餐。
- 节奏要点：卷饼全程「熟饭 + 熟馅」双熟，煎锅和饭锅都别空；烙饼提前囤。

## 陷阱与注意

- 卷饼要「熟饭 + 熟馅」，任一不熟就废单。
- 本关 4 星门槛（1400）偏高，连击与按顺序出餐是关键；断一单节奏难追回。
- 脏盘回收路线可能较长，别让脏盘断供。
