# 饥饿之夜 敌群 1（Night of the Hangry Horde Horde 1）

## 元信息

- 关卡编号：`horde-1`
- 战役：Night of the Hangry Horde（万圣节 / 饥饿之夜，敌群 / horde 特殊关）
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P
- 玩法：防守（horde），非计时做菜

## 星级门槛（2P）

本关为敌群防守关，**无分数门槛**，按「厨房血量 + 存活波次」评星：

| 星级 | 条件 |
|---|---|
| 1★ | 存活全部 3 波（厨房血量 > 0） |
| 2★ | 存活全部 3 波（厨房血量较高） |
| 3★（黄旗） | 存活全部 3 波且**厨房满血** |

> 敌群关满星只有 3 星（黄旗），须全程满血（不被敌人破窗掉血）。本关共 **3 波**，是敌群玩法的教学关。

## 菜谱 / 订单（防守：做菜喂敌人）

- 本关要做的是**汉堡**（复用本体菜谱），喂给攻城的敌人：
  - 普通汉堡：切好煎熟的肉排 + 汉堡面包。
  - 芝士汉堡：普通汉堡 + 切好的奶酪。
  - 生菜芝士汉堡：芝士汉堡 + 切好的生菜。
- 每个窗口会显示敌人要的菜，做出对应菜端到该窗口喂给它，喂饱换金币。

## 关卡机制 / 地形（防守要点）

- **波次 + 血条**：屏幕下方有厨房血条，厨房周围有若干出餐窗口；本关共 **2 个窗口**、**3 波**。
- 敌人（不死面包 unbread 等）会扒在窗口木板上，一边等菜一边拆木板；做出菜喂它才能让它退走。
- 喂饱敌人得**金币**，金币可**修补窗口木板**（阻止敌人破窗）和**解锁捷径**（更快在厨房内移动）。
- 敌人破窗会扣厨房血条；**血条满 = 3 星**，掉血就没黄旗。
- 本关是教学关，窗口少、波次短，没有其它机关。

## 打法与分工（2P）

- 通用防守优先级：**① 先喂最接近破窗的敌人 → ② 补木板 → ③ 继续做菜**。
- 推荐分工：
  - 玩家：守**煎肉排 + 出餐喂敌**，优先处理窗口告急的订单。
  - 你：守**切肉排 / 切奶酪 / 切生菜 + 备面包**，把半成品投给玩家；窗口告急时帮忙补木板。
- 流程顺序：开局先看清 2 个窗口各要什么汉堡 → 批量切肉煎肉 → 按「谁快破窗先喂谁」出餐 → 有金币就补最危险的窗口木板。

## 陷阱与注意

- 汉堡要「熟肉排 + 面包」，肉排没煎熟就喂会做不出菜、浪费一次。
- 教学关敌人拆板慢，但别大意：一旦有窗口木板快被拆穿，先补板再继续做菜。
- 满血才有 3 星，宁可少做一单也要优先保住窗口不破。
