# 饥饿之夜 敌群 2（Night of the Hangry Horde Horde 2）

## 元信息

- 关卡编号：`horde-2`
- 战役：Night of the Hangry Horde（万圣节 / 饥饿之夜，敌群 / horde 特殊关）
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P
- 玩法：防守（horde），非计时做菜

## 星级门槛（2P）

本关为敌群防守关，**无分数门槛**，按「厨房血量 + 存活波次」评星：

| 星级 | 条件 |
|---|---|
| 1★ | 存活全部 4 波（厨房血量 > 0） |
| 2★ | 存活全部 4 波（厨房血量较高） |
| 3★（黄旗） | 存活全部 4 波且**厨房满血** |

> 敌群关满星只有 3 星（黄旗）。本关共 **4 波**。

## 菜谱 / 订单（防守：做菜喂敌人）

- 本关要做的是**披萨**（复用本体菜谱），喂给攻城的敌人：
  - 芝士披萨：切好的面团 + 奶酪 + 番茄 → 组合 → 进披萨烤箱烤。
  - 香肠披萨：芝士披萨 + 切好的香肠。
- 每个窗口显示敌人要的披萨，做出来端到对应窗口喂它换金币。

## 关卡机制 / 地形（防守要点）

- **波次 + 血条**：本关共 **3 个窗口**、**4 波**。
- **中央台面分隔**：厨房被中央柜台分成两半；**下方是食材箱、盘子、烤箱，上方是洗碗池和窗口**。
- 敌人拆木板等菜，喂饱得金币；金币补窗口木板 / 解锁捷径；破窗扣厨房血条，满血才 3 星。
- 布局要点：烤披萨在下方、喂敌窗口在上方，**披萨出炉要往上送**，提前规划上行路线。

## 打法与分工（2P）

- 通用防守优先级：**① 先喂最接近破窗的敌人 → ② 补木板 → ③ 继续做菜**。
- 推荐分工：
  - 玩家：守**下方烤箱 + 切面团/奶酪/番茄/香肠**，烤好披萨往上投/送。
  - 你：守**上方窗口 + 补木板 + 洗碗**，接披萨喂对应窗口；窗口告急先补板。
- 流程顺序：开局看清 3 个窗口要什么披萨 → 下方批量切料烤披萨 → 上方按「谁快破窗先喂谁」出餐 → 有金币补最危险窗口。

## 陷阱与注意

- 披萨要烤熟，没烤熟/烤糊都不能喂。
- 上下分隔，披萨上行有搬运成本：用投掷跨中央台面，别端着来回跑。
- 3 个窗口同时告急时，先救「木板最薄的」；满血才有 3 星。
