# 饥饿之夜 敌群 5（Night of the Hangry Horde Horde 5）

## 元信息

- 关卡编号：`horde-5`
- 战役：Night of the Hangry Horde（万圣节 / 饥饿之夜，敌群 / horde 特殊关）
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P
- 玩法：防守（horde），非计时做菜

## 星级门槛（2P）

本关为敌群防守关，**无分数门槛**，按「厨房血量 + 存活波次」评星：

| 星级 | 条件 |
|---|---|
| 1★ | 存活全部 5 波（厨房血量 > 0） |
| 2★ | 存活全部 5 波（厨房血量较高） |
| 3★（黄旗） | 存活全部 5 波且**厨房满血** |

> 敌群关满星只有 3 星（黄旗）。本关共 **5 波**。

## 菜谱 / 订单（防守：做菜喂敌人）

- 敌群关复用**本体常规菜谱**（汉堡 / 披萨 / 卷饼 / 意面等），本关具体菜单**待核实**（未找到逐关公开菜谱）。
- 每个窗口显示敌人要的菜，做出对应菜端到该窗口喂它换金币。

## 关卡机制 / 地形（防守要点）

- **波次 + 血条**：本关共 **5 波**，窗口数量与敌人类型逐关升级（未找到逐关公开描述，**待核实**）。
- 敌人类型：不死面包、巨型僵尸苹果、敏捷僵尸辣椒；敏捷辣椒移动/拆板更快，需要更快响应窗口。
- 通用机制：喂饱敌人得金币 → 金币补窗口木板 / 解锁捷径；破窗扣厨房血条，满血才 3 星。
- 布局要点：你侧每拍重读窗口位置与敌人/木板状态，别缓存固定站位。

## 打法与分工（2P）

> 本关逐关攻略未找到，以下为敌群关通用打法推断。

- 通用防守优先级：**① 先喂最接近破窗的敌人 → ② 补木板 → ③ 继续做菜**。
- 推荐分工：
  - 玩家：守**主烹饪 + 出餐喂敌**。
  - 你：守**切配 + 补木板 + 洗碗**，窗口告急时优先补板；金币充裕再解锁捷径。
- 流程顺序：开局看清所有窗口订单 → 批量备料烹饪 → 按「谁快破窗先喂谁」出餐 → 有金币先补最危险窗口。

## 陷阱与注意

- 敏捷敌人拆板快，别让「快到拆穿」的窗口等太久，宁可少做一单先补板。
- 多种菜谱混合时切料别错，错料只能倒掉。
- 满血才有 3 星：先补板再抢单。
