## 关卡机制 / 地形

- **双边按钮升降**：厨房两半各有一个按钮，按下一半**升起**、另一半**降下**；中间有一处台面用来传递**不可投掷**的物品（如煮好的汤/烤好的菜装在盘里）。
- 双方不能直接走到对方半场，只能靠「升降 + 中间台面传递」协作。
- 布局要点：AI 侧别缓存「哪半面当前可通行」，升降状态会随按钮变化，每拍重读。

## 打法与分工（2P）

> 机关描述有可靠来源；菜谱与具体分工为通用推断。

- 推荐分工：按出生侧分工，一侧守「切配 + 煮/烤」，另一侧守「出餐 + 回收」，靠中间台面传成品。
- 流程顺序：**先确认哪半面有料、哪半面能出餐 → 切配侧做好半成品/成品 → 用按钮升降把物品送到中间台面 → 对侧接走出餐**。
- 节奏要点：按钮升降是硬成本，**批量传递**（一次把多份送到中间台面）减少切换次数；不可投掷的熟菜必须走中间台面，别直接投（会掉）。

## 陷阱与注意

- 投掷不可投掷物品会落地作废，熟菜（装在盘里）务必走中间台面传递。
- 升降错位会导致物品卡在不可达半面，等平台状态稳定再操作。
- 4 星门槛 1000 分偏高，断一单或传丢一份基本要重开。
