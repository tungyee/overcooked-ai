## 菜谱 / 订单

凯文关通用主菜是「蒸菜」，有两种成品，订单会混合出现：

- 蒸包子 / 蒸饺：面粉 + 底料（肉排 / 虾肉 / 胡萝卜）。底料先切，再和面粉一起进搅拌机搅成生包子，最后上蒸笼蒸熟。
- 蒸鱼：鱼肉切好后直接上蒸笼蒸熟（不需要搅拌机）。

本关两种菜都会出现，需按订单区分「带馅蒸包」与「清蒸鱼」。带馅蒸包是 3 步菜（切 → 搅 → 蒸），是本关的耗时瓶颈。

## 关卡机制 / 地形

- 移动范围被完全分隔成左右两半，双方不能直接走过去，只能靠**投掷**或中间台面传递食材。
- 一侧是搅拌机 + 砧板（切底料、搅拌成生包子），另一侧是蒸笼 + 出餐口 + 面粉箱 + 鱼肉（切鱼、蒸、出餐）。
- 无移动平台 / 火等干扰机关，是纯节奏关：四星门槛高（1460），基本拼手速与投掷准度。

## 打法与分工（2P）

以出生侧为准，两侧职责可互换（谁在搅拌机侧就做搅拌，谁在蒸笼侧就做蒸）：

- 搅拌机侧：切肉排 / 虾肉 / 胡萝卜 → 与面粉一起进搅拌机搅成生包子 → 投给蒸笼侧；顺带负责洗碗。
- 蒸笼侧：把面粉投给搅拌机侧；切鱼肉；接收搅拌好的生包子进蒸笼；蒸熟后装盘出餐；回收脏盘投回搅拌机侧。

流程节奏：

1. 开局先让面粉跨到搅拌机侧，同时搅拌机侧开始切底料。
2. 搅拌机持续出「生包子」，蒸笼侧持续蒸、出餐，形成单向流水线（面粉 → 馅 → 蒸 → 出餐）。
3. 清蒸鱼是短流程菜，可在蒸包等待时插空补上，维持连击。
4. 蒸包最耗时，**始终保持搅拌机与蒸笼都不空**：搅拌机侧备好切好的底料，蒸笼侧蒸笼里始终有货。

## 陷阱与注意

- 投掷不准：面粉 / 生包子掉到地上会污染地面、浪费时间，需按投掷弧线站位；把消火器挪开，避免投掷失败时被台面挡住。
- 连击：按订单顺序出菜；清蒸鱼与蒸包是不同订单，做错会断连，四星下基本要重开。
- 蒸笼侧同时要切鱼 + 蒸 + 出餐，容易忙不过来；搅拌机侧有余力时可帮投递 / 回收脏盘。
