## 菜谱 / 订单

- 蒸包子 / 蒸饺：底料（肉排 / 虾肉 / 胡萝卜）切好，与面粉一起进搅拌机搅成生包子，上蒸笼蒸熟。
- 蒸鱼：鱼肉切好后直接蒸熟。
- 订单按蒸包 / 蒸鱼区分，蒸包 3 步最耗时。

## 关卡机制 / 地形

- 4 个调理工位（搅拌机 / 蒸笼等）**按一定周期顺时针旋转换位**，烹饪进行到一半也会被换走。
- 换位后工位在别处，角色需要跟着走；正在搅拌 / 蒸的东西会随工位移动，需重新找到它。
- 无其他伤害机关，主要难点是「换位带来的状态丢失感」。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断（结合蒸包流程与旋转工位机制）。

- 建议按「菜」而非「固定站位」分工，减少被旋转工位牵着走：
  - 玩家：负责蒸包线——切底料、投进搅拌机、取出生包子去蒸。
  - 你：负责蒸鱼线 + 出餐——切鱼、蒸鱼、接收蒸包、统一出餐、洗盘子。
- 工位旋转时**只跟当前手里的半成品走，不要跟着某个工位跑**；先把手里的工序收尾，再根据新布局继续。
- 每一圈旋转后重新认一遍「搅拌机在哪、蒸笼在哪、出餐口在哪」，宁可停半拍也不要站错位。
- 保持搅拌机与蒸笼都不空；蒸包备料提前切好放在砧板上，减少换位后的找料时间。

## 陷阱与注意

- 换位瞬间投掷容易落空：等工位停稳再投，别在旋转途中丢生包子。
- 半成品「消失感」：生包子 / 蒸笼会随工位转走，记住自己最后放在哪个工位上，换位后去新位置找。
- 断供风险高于烧糊：旋转会打断节奏，优先保证出餐口有货，其次再追高连击。
