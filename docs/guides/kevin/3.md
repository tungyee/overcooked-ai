## 菜谱 / 订单

- 蒸包子 / 蒸饺：底料切好 + 面粉进搅拌机搅成生包子 → 蒸笼蒸熟。
- 蒸鱼：鱼肉切好直接蒸。
- 订单按蒸包 / 蒸鱼区分。

## 关卡机制 / 地形

- **中央足场会升降**：切料、搅拌、蒸都要穿过这块升降平台。
- 平台升起时可通行 / 交互，降下时路被隔断；高低差决定了两侧何时能互相传递食材。
- 本质是「高低差通道」关卡：如何卡平台升起的窗口，是节奏关键。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断。

- 建议按「两侧」分工，中间平台作为唯一通道：
  - 一侧（砧板 + 搅拌机）：切底料、搅拌成生包子。
  - 另一侧（蒸笼 + 出餐）：蒸、出餐、洗盘子。
- 平台升起时集中「跨侧传递」：生包子、脏盘、切好的料都在升起窗口一次性交换，减少反复过桥。
- 平台降下时各自在本侧做纯本地工序（切料、蒸、洗盘），不要干等。
- 保持搅拌机与蒸笼不空；生包子一次攒两三个，等平台升起一起送过去蒸。

## 陷阱与注意

- 平台降下时若带着生包子 / 熟菜站在半途，可能被卡在错误一侧，导致断供。
- 投掷过升降平台要等升起、且注意高低差可能挡住抛物线。
- 两侧工作不均衡容易一方空转；平台降下时是补料 / 洗碗的窗口，主动找活干。
