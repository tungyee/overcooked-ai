## 菜谱 / 订单

- 蒸包子 / 蒸饺：底料切好 + 面粉进搅拌机搅成生包子 → 蒸笼蒸熟。
- 蒸鱼：鱼肉切好直接蒸。
- 订单按蒸包 / 蒸鱼区分。

## 关卡机制 / 地形

- **中央会起火，火焰向四周飞散，火灾频繁**：移动路线经常被火堵住。
- 需要反复拿灭火器灭火，把通道重新打通。
- 灭火器是移动路线的「钥匙」：不清火，切料 / 蒸 / 出餐都会被隔断。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断。

- 建议一名玩家主「烹饪流水线」、另一名主「救火 + 补给」：
  - P1（队友）：主烹饪——切底料、搅拌、蒸、出餐。
  - P2（你 / AI）：主救火 + 补位——盯火情、清出通道、递料、洗碗；火灭后立刻回流水线帮切 / 蒸。
- 火刚起时优先灭，别让火封死搅拌机 ↔ 蒸笼的唯一通道；通道一通，马上恢复双向传递。
- 保持搅拌机与蒸笼不空；趁灭火空档把备料切好，减少火情对节奏的伤害。

## 陷阱与注意

- 火灾蔓延快，漏灭一次可能把出餐口或蒸笼围死，导致断供。
- 救火时别把手里的生包子 / 熟菜放在会被火吞的位置。
- 火焰造成的移动绕行比想象耗时，宁可早灭 1 秒也不要赌火不会扩散。
