## 菜谱 / 订单

- 蒸包子 / 蒸饺：底料切好 + 面粉进搅拌机搅成生包子 → 蒸笼蒸熟。
- 蒸鱼：鱼肉切好直接蒸。
- 订单按蒸包 / 蒸鱼区分。

## 关卡机制 / 地形

- **中央道路有车辆频繁驶过**，穿过道路时会被车撞飞。
- 出餐 / 递料经常需要横穿这条道路，被撞会把手里做好的菜弄丢。
- 车辆按固定节奏来往：关键是在「车流间隙」穿行，或绕开中央道路。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断。

- 建议两侧分工，中央道路只用于「必要跨越」，不频繁来回：
  - 一侧（砧板 + 搅拌机）：切底料、搅拌生包子。
  - 另一侧（蒸笼 + 出餐）：蒸、出餐、洗盘子。
- 生包子 / 脏盘跨路时**先观察车流，等间隙再投掷或跑过**；熟菜绝对不冒险横穿。
- 尽量把「跨路」动作合并成批次：攒 2~3 个生包子一次性投/递过去，减少穿行次数。
- 保持搅拌机与蒸笼不空；被车撞掉一个菜约等于断一单，宁慢勿撞。

## 陷阱与注意

- 端着熟菜横穿被撞 = 白做 + 断供，是本关最大翻车点。
- 投掷过路时抛物线可能被车挡住 / 干扰，选车辆刚驶离的窗口投。
- 别为了抢 1 秒贴车尾跑，车辆判定比看起来宽。
