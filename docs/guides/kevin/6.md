## 菜谱 / 订单

## 关卡机制 / 地形

- **地板像传送带一样持续移动**，站着也会被带着走，很难自由定位 / 停住。
- 想把手里的食材放在某个台面 / 工位上，会因脚下传送而放偏。
- 移动 + 放置都受传送方向影响，需要顺着传送带规划动线。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断。

- 建议按「顺传送带方向」分工，减少逆流走位：
  - 一名玩家主「切 + 搅」：顺着传送带在上游切料、进搅拌机。
  - 另一名玩家主「蒸 + 出餐」：在下游接收生包子、蒸、出餐、洗碗。
- 传送带方向即流水线方向：料从上游流向下游，尽量只做「顺流」动作，不逆流折返。
- 放置时对台面要「提前量」：算上传送带位移，把料扔 / 放到工位稍上游的位置。
- 保持搅拌机与蒸笼不空；优先用投掷代替走过去放置，减少被传送带带偏的次数。

## 陷阱与注意

- 逆着传送带跑非常慢，别图省事逆流，绕半圈顺流反而更快。
- 放料放偏是本关典型失误：半成品落在传送带上会被带走，甚至掉到错误工位。
- 出餐口 / 蒸笼的位置要反复确认，因为人在传送带上会不断漂移，容易「以为到了其实没到」。
