## 菜谱 / 订单

- 蒸包子 / 蒸饺：底料切好 + 面粉进搅拌机搅成生包子 → 蒸笼蒸熟。
- 蒸鱼：鱼肉切好直接蒸。
- 订单按蒸包 / 蒸鱼区分。

## 关卡机制 / 地形

- **食材 / 盘子的交接点很少**，双方想要的食材往往不在自己这一侧。
- 两侧都拿不到对方手里的东西，只能靠少数几个交接点传递。
- 沟通「我需要什么 / 我手里有什么」是效率核心；交接时机是关键。

## 打法与分工（2P）

> 未找到逐关的公开双人攻略，以下分工为通用打法推断。

- 建议固定两侧职责，交接点只传「必需跨侧的东西」：
  - 一侧（砧板 + 搅拌机）：切底料、搅拌生包子。
  - 另一侧（蒸笼 + 出餐）：蒸、出餐、洗盘子、切鱼（若鱼在蒸笼侧）。
- 把跨侧传递统一成一个「中转台」：生包子、脏盘、面粉都往同一个交接点放，双方定时去取。
- 用简短状态沟通代替来回找：「要馅」「要面」「要盘」「有包子」——减少无效跑动。
- 保持搅拌机与蒸笼不空；交接点有货就尽快取走，避免占位堵住下一条传递。

## 陷阱与注意

- 交接点少 → 一方「等料」时最浪费时间，提前把下一单需要的料备在交接点。
- 双方同时想用交接点会互相撞；约定「先放后取、放完就走」。
- 断连风险高（多人需 8 连击解锁，说明本关节奏被交接点卡住），优先保连击，少做非必需传递。
