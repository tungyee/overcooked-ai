## 菜谱 / 订单

## 关卡机制 / 地形

- **食材由传送带持续送进来**，不同传送带出不同料：必须记住「哪条传送带出面粉 / 肉 / 虾 / 胡萝卜 / 鱼」，这是全关最重要的信息（详见下方「流水线要点」）。

- 传送带 + 动态布局叠加，意味着「料从哪来、工位在哪、出餐口在哪」都会变，稍一错位就是断单。

## 打法与分工（2P）

> 未找到逐关的公开双人详细攻略；以下为结合机制描述的通用打法推断（菜谱与「传送带供料」有可靠来源）。

### 通用原则（本关比前 7 关更吃重）

1. 先花开局几秒**观察各传送带出口的食材种类**，在心里标好「面 / 肉 / 虾 / 胡萝卜 / 鱼」各自从哪条带出来。
2. 流水线只做一个方向：**传送带出口 → 砧板 → 搅拌机 → 蒸笼 → 出餐口**，尽量顺流不折返。
3. 低容错 = 断一单就可能掉星：**优先保连击**，宁可让某单慢一点，也不要乱序 / 烧糊。
4. 动态布局变化时，先收尾手里的半成品，再按新布局重新认工位，不要凭旧记忆走位。

### 分工建议

- P1（队友）主「切 + 搅」：守在传送带出料口附近，接料 → 切底料 → 进搅拌机出「生包子」。
- P2（你 / AI）主「蒸 + 出餐 + 补位」：接收生包子 → 蒸 → 出餐 → 回收脏盘；空闲时帮切鱼 / 接传送带漏料。
- 蒸鱼是短流程菜，谁离鱼出口近谁顺手做，用来在蒸包等待时保连击。

### 流水线要点

- 生包子是唯一必须「跨段传递」的半成品：搅拌机侧做好后要送到蒸笼侧。用投掷跨越中间地带，比跑过去省时间。
- 面粉和底料都从传送带出来时，优先接住「当前订单最缺」的那种，别被传送带节奏带乱。
- 蒸笼、搅拌机都不空是底线；动态换位后第一件事是确认这俩工位的新位置。

## 陷阱与注意

- 传送带不停供料，容易在砧板 / 地上堆料：**别囤超过手边能消化的量**，否则传送带口会被堵，料掉地上。
- 动态换位瞬间投掷 / 放置易落空：等布局停稳再操作半成品。
- 烧糊与断供并存：蒸包蒸久会糊，蒸笼侧要盯熟；搅拌机侧别断生包子供应。
- 出餐口可能随布局移动，端熟菜去出餐前先确认当前出餐口位置，避免端着菜跑错方向。
