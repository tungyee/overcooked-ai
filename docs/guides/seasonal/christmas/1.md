## 菜谱 / 订单

- 圣诞战役官方食谱为**肉馅派（mince pies）、圣诞布丁（Christmas pudding）、热巧克力（hot chocolate）**三道甜品（Team17 官方）。
- 肉馅派：派皮+馅料 → 烤；圣诞布丁：混合料 → 蒸/煮；热巧克力：牛奶+巧克力 → 加热 → 装杯（确切工序以进关后订单/食材箱为准）。
- 具体每关做哪几道以进关后的订单为准（AI 从快照读订单即可）。

## 关卡机制 / 地形

- 本战役特色障碍是**冰面（ice，脚滑）**与**会消失的平台（disappearing platforms，时隐时现）**（SuperParent）。
- 本关为第 1 关（入门关），主要熟悉冰面走位与甜品并行节奏。

## 打法与分工（2P）

- **首单出餐才计时**（novarcan 本关标注）：开局可先备料。
- 建议分工：
  - 玩家：负责需要烤/蒸的慢菜（肉馅派、圣诞布丁）。
  - 你：负责热巧克力（快菜）+ 装盘出餐，顺带取料投给玩家。
- 节奏：烤/蒸的菜慢、热巧克力快；快菜保底，慢菜按节奏成批做。

## 陷阱与注意

- **冰面**：跑动会打滑，别冲过头掉下平台；拐弯提前减速。
- **消失的平台**：别站上去、别把料放上去；等它显形再走/再放。
- 甜品烧糊会起火，烤/蒸熟料及时端。
