## 菜谱 / 订单

本战役唯一新食谱是**月饼（Mooncake）**，官方确认有 3 种口味：

- 原味（莲蓉馅）
- 蛋黄（咸蛋黄馅）
- 伍仁（五仁馅）

工序为通用推断（无公开逐关食谱，待核实）：月饼皮（面团）+ 馅料 → 混合 / 包馅 → 烤制。

## 关卡机制 / 地形

- 中秋主题厨房建在水面上，用**睡莲叶（lily pads）**连接各区域。
- 睡莲叶是新增动态危害：踩上去会下沉（把人/食材带下水），必须快速通过、别停留。
- 各关的睡莲叶布局与站点分布未找到公开逐关资料（待核实）。

## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 睡莲叶是核心节奏点：跨区前先观察叶子沉浮规律，一次通过、不在叶上停留或投掷。
- 分工建议：两人各守一片「被水隔开的」区域，用投掷跨水面传月饼皮 / 馅料，减少踩叶次数。
- 先备馅料（莲蓉 / 蛋黄 / 伍仁），再包皮烤制；烤炉不空，烤好秒端（易糊）。

## 陷阱与注意

- 睡莲叶下沉会把人带下水（损失约数秒复活），是最大时间陷阱；别贴着叶子边缘走位。
- 月饼烤糊会起火；分人救火会打断跨水面节奏。
- 投掷跨水面时注意弧线，掉进水里就是白费。
