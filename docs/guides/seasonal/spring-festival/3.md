## 菜谱 / 订单

- 同战役食谱：**火锅（hot pot）+ 水果拼盘（fruit platter）**（部分来源另有「点心/虾饺 dim sum」）。
- 4★ 门槛最高，订单量大、火锅要成批做；水果拼盘作为快菜补足单量。
- 具体订单以进关后为准。

## 关卡机制 / 地形

- **巨锅（wok）**：火升起来才熟、火下去停火；本关火力窗口节奏更紧，锅位可能离备料区较远（据 bilibili 单人攻略：锅挪太远时可先不挪，切菜时间够等下一波火）。
- 无公开逐关布局文档，地形细节以实机快照为准。

## 打法与分工（2P）

- 建议分工：
  - P1（队友）：专职火锅——按火力窗口成批下料、及时端走，火灭去取料/切水果补位。
  - P2（你 / AI）：切水果装盘出餐，并把火锅料投到锅边；必要时接手端锅。
- 节奏：**火力上来→下料；火力下去→切水果/备料**，两手不空。火锅别等单子来了才做，提前按火力窗口囤熟料。

## 陷阱与注意

- 锅离料区远时别来回空跑：火没起来先去切水果，火起来再赶去下料。
- 断火下料 = 占锅不熟，直接拖垮节奏。
- 4★ 门槛高，容错低：水果拼盘一旦断供就补不回单量。
