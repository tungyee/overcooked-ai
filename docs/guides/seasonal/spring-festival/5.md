## 关卡机制 / 地形

- **巨锅（wok）**：火升起来才熟、火下去停火。
- 作为战役收尾关，可能综合前面几关的走位/移动要素（无公开文档，以实机快照为准）。

## 打法与分工（2P）

- 建议分工：
  - 玩家：盯巨锅，火力窗口下料、端锅；火灭去备料。
  - 你：水果拼盘切+装+出餐，投火锅料给玩家。
- 节奏：同前几关——火力上来下火锅料，火力间歇切水果；把前几关练熟的「火力窗口节奏」复用到收尾关。

## 陷阱与注意

- 巨锅断火下料无效，火起来再下。
- 火锅烧糊会起火，熟料及时端走。
- 若本关有移动地形，别把囤料放在移动路径上。
