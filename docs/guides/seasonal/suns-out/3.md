## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 维持热狗流水线不空：香肠锅始终有货，面包提前切好堆在组装位旁。
- 冰淇淋浮乐朵 / 沙拉若与热狗同场轮换，两人要各认领一类订单，避免混做。
- 花车移动间隙是跨区投掷 / 传料窗口，抓紧空隙，别在移动面上逗留。

## 陷阱与注意

- 烟花火险 + 花车叠加时最乱：先救火、再补货、后出餐，优先级别错。
- 酱料加错废单；组装前先看订单。
- 投掷跨区要提前站位，花车挡住弧线会掉食材。
