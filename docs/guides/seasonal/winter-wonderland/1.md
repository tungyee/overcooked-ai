## 菜谱 / 订单

本战役共用 5 款节庆食谱（官方确认），各关从中轮换：

- 热巧克力（Hot Chocolate）
- 煎饼 / 班戟（Pancakes）
- 烤肉晚宴（Roast Dinners）
- 圣诞布丁（Christmas Puddings）
- 肉碎批 / 肉馅饼（Mince Pies）

工序为通用推断（无公开逐关食谱，待核实）：热巧克力 ≈ 牛奶 + 巧克力加热；煎饼 ≈ 面粉 + 鸡蛋搅拌后煎；烤肉晚宴 ≈ 肉类进烤炉；圣诞布丁 / 肉碎批 ≈ 面团类进烤炉。

## 关卡机制 / 地形

- 冬日奇境 5 关是 2019 年 3 个 DLC 关卡的「节日换装」：1 关复用 Campfire Cook Off 的**可穿戴背包**（随身携带食材）、2 关复用 Carnival of Chaos 的**大炮**（厨师乘炮跨区）、2 关复用 Night of the Hangry Horde 的**敌群防守**（即本战役的敌群关 1-4 / 1-5）。
- 本关为流程关，具体复用背包还是大炮机制未找到公开资料（待核实）；两种机制对 AI 的关键影响是「跨区 / 携带」方式不同。

## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 两人按站点就近分区：一人守「原料 + 切/煮」侧，一人守「组装 + 出餐」侧，具体分区以实际出生点为准。
- 先启动耗时最长的熟料（烤肉 / 布丁等），等待期并行切备短流程菜（热巧克力 / 煎饼），熟料一好立即组装出餐。
- 若有可穿戴背包：把共享原料（面粉 / 牛奶等）装进背包，减少来回跑动。
- 若有大炮：只用它做一次性跨区，不要依赖它送关键熟料（滞空期间无法接料 / 救火）。

## 陷阱与注意

- 节庆关普遍有移动 / 分隔地形，投掷是跨区传料的主要手段，站位要对准投掷弧线。
- 烤肉 / 布丁易烧糊起火，熟了一定端走；起火会占用救火时间。
