## 关卡机制 / 地形

- 冬日奇境 5 关复用 2019 年 3 个 DLC 的机制：1 关 Campfire 背包、2 关 Carnival 大炮、2 关 Horde 敌群（1-4 / 1-5）。
- 本关为流程关，可能涉及大炮跨区或背包携带，具体分配待核实。
- 大炮机制要点：厨师可进炮发射到对侧，适合一次性转移，但不适合频繁往返。

## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 先启动耗时最长的熟料（烤肉 / 布丁），等待期做热巧克力 / 煎饼等短流程单。
- 若本关有大炮：一人留一侧出餐，另一人用炮跨区去取原料 / 熟料；发射后落地位置固定，注意提前瞄准。
- 若本关有背包：把面粉 / 牛奶这类用量大的原料装包，减少两个厨师同时挤在原料箱旁。

## 陷阱与注意

- 大炮滞空期间无法救火，出餐侧着火时别正在空中。
- 烤肉 / 布丁熟了一定端走，糊锅起火会打乱整条流水线。
- 分隔地形下，投掷准度决定效率，掉地上的食材会污染地面。
