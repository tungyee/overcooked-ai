## 菜谱 / 订单

## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 吞吐型流程关核心是「灶 / 烤炉不空」：始终保证有熟料在加热，出餐手不停。
- 分工建议：一人专守「原料 → 切/搅 → 进锅/炉」，一人专守「熟料 → 组装 → 出餐」，减少两人在站点间互相换手。
- 短流程菜（热巧克力 / 煎饼）用来填空档维持连击，长流程菜（烤肉 / 布丁）提前下锅。

## 陷阱与注意

- 订单密度高时最容易断供：原料箱被清空前就要补，别等订单来才现取。
- 糊锅起火在此类高节奏关里代价极大，熟料必须秒端。
- 分隔 / 移动地形下，投掷准确度直接决定上限。
