## 菜谱 / 打法（防守玩法）

- 防守玩法：节日敌人（拐杖糖等）一波波逼近，完成节庆食谱订单（热巧克力 / 煎饼 / 烤肉晚宴 / 圣诞布丁 / 肉碎批）击退敌人。
- 敌人漏过防线会扣厨房血量，满血通关才有星。

## 关卡机制 / 地形

- 复用 Night of the Hangry Horde 的敌群玩法（本战役第 2 个 Horde 来源关）。
- 厨房有血量条，敌人沿固定路径推进；本关与敌群 1 的差异（敌人种类 / 波次 / 地形）未找到公开资料，待核实。

## 打法与分工（2P）

> 未找到公开攻略，以下为通用打法推断。

- 流水线分工：一人守原料 + 灶台持续做菜，一人守出餐口 / 防线补刀。
- 先看清本关敌人推进路径，把守线人固定在最靠近防线的出餐位。
- 持续出餐优先于做「大单」，短流程菜（热巧克力 / 煎饼）适合快速连续击退。
- 投掷传菜给守线人，减少跑动。

## 陷阱与注意

- 满血才有 3 星，漏怪即掉血，掉血基本重开。
- 灶台 / 烤炉不空，避免糊锅起火占用救火人手。
- 两人别同时离开防线。
