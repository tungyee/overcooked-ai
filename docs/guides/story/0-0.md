## 菜谱 / 订单

- 沙拉：生菜（切碎）→ 装盘；生菜 + 番茄（都切碎）→ 同一盘。
- 只切不煮，无烹饪、无米饭、无海苔。洋葱国王在旁边逐步引导，纯教学。
- 订单两种：生菜沙拉、生菜番茄沙拉。

## 关卡机制 / 地形

- 洋葱王国城堡厨房，布局简单对称，无机关、无传送带、无灶台。
- 一侧是食材箱（生菜、番茄），一侧是砧板，出餐口附近有干净盘。
- 教学点依次是：移动、取料、切菜、装盘、出餐（给第一波僵尸面包上菜）。

## 打法与分工（2P）

- P1（队友）：取生菜/番茄，放到中央台面。
- P2（你 / AI）：切菜、装盘、送餐。
- 门槛极低（3★ 仅 60 分），按订单顺序做、保持连击即可，不必追求速度。

## 陷阱与注意

- 无实质难点。切好的菜及时装盘出餐，别占着砧板。
