# 寿司城 1-1（主线 1-1）

## 元信息

- 关卡编号：`1-1`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：`Sushi_1_1`（双人版 `Sushi_1_1_2P`；仓库实测录制帧也见 `Sushi_1_1S_2P`）
- 玩家数：2P

## 星级门槛（2P）

| 星级 | 分数 |
|---|---|
| 1★ | 20 |
| 2★ | 160 |
| 3★ | 300 |
| 4★ | 2650 |

## 菜谱 / 订单

- 刺身（只切不煮）：鱼 / 虾切好直接装盘。
- 鱼（SushiFish）→ 切碎 → 装盘；虾（SushiPrawn）→ 切碎 → 装盘。
- 无米饭、无海苔、无烹饪（本关无灶台）。

## 关卡机制 / 地形

- 教学关，无机关、无灶台。左右基本对称：P1 出生左侧，P2 出生右侧。
- 左上角垃圾桶与鱼箱；右上角出餐口、盘回收与虾箱；底部一排 4 个砧板（左右各 2）。
- 中央 4 个假柜台，初始各有一叠干净盘。

## 打法与分工（2P）

- 双方各管一侧的箱子与砧板：各切各的鱼/虾，切好装盘送餐。
- 鱼、虾都要切（chop_stages 8），切完直接装盘，无后续工序。
- 本关是「第一道菜未出前不计时」的囤菜关：开场可先囤一批切好的刺身再集中出餐。3★ 只需 300 分不难，但 4★ 高达 2650，靠囤料 + 连击。

## 陷阱与注意

- 只切不煮，容易漏掉「多切几份」的机会；切好的料别堆在砧板上占位。
- 出餐口占地 2 格（竖），交互格在上半格，贴近再按。
