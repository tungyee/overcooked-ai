# 寿司城 1-2（主线 1-2）

## 元信息

- 关卡编号：`1-2`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：`Sushi_1_2`（双人版 `Sushi_1_2_2P`）
- 玩家数：2P

| 1★ | 60 |

## 菜谱 / 订单

- 寿司卷：海苔 + 熟寿司饭 + 切好的鱼。
- 米饭（SushiRice）→ 煮熟（BoiledSushiRice）；鱼（SushiFish）→ 切碎；海苔（Seaweed）直接取。
- 装盘 = 海苔 + 熟米饭 + 切好的鱼，然后出餐。

## 关卡机制 / 地形

- 无传送带。顶部一排是加工区（3 砧板 + 出餐口 + 盘回收），底部一排是煮饭区（3 灶台 + 垃圾桶）。
- 3 个箱子全在中线（米饭/鱼/海苔各一），两侧开敞，取料路径短。
- 出餐口寻路占地 2 格（横），交互格单格；底部是墙，左右半区只能从上/中/下三排直穿。

## 打法与分工（2P）

- 灶台（底部煮饭区）的人：负责煮饭（米下锅、看火、熟了端锅/装盘），兼顾运输。
- 砧板（顶部加工区）的人：负责切鱼、铺海苔、装盘、送餐。
- 关键分工点：煮饭的人要一直盯着锅，饭熟了立刻盛出，否则糊锅起火。
- 本关也是「第一道菜未出前不计时」：可先煮好一批饭、切好一批鱼再集中出餐（4★ 2200 需要囤料）。

## 陷阱与注意

- 米饭煮久会糊锅起火，煮饭的人不能走神；熟了立刻端走。
- 底部是墙，别试图从底部绕行。
