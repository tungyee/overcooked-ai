## 菜谱 / 订单

- 黄瓜寿司卷：海苔 + 熟寿司饭 + 切好的黄瓜。
- 虾刺身：虾切好直接装盘。
- 米饭（SushiRice）→ 煮熟；黄瓜（Cucumber）→ 切碎；虾（SushiPrawn）→ 切碎；海苔直接取。

## 关卡机制 / 地形

- 左右分厨、无传送带：左侧 = 切菜区（3 砧板 + 海苔/虾/米饭箱 + 出餐口）；右侧 = 煮饭区（3 灶台 + 黄瓜箱 + 洗碗池 + 盘回收）。
- 中间一列柜台是左右两区的中转台；底部有一条左右互通的下通道。
- 关键点：食材与加工站交叉——米饭/虾在左箱、灶台在右；黄瓜在右箱、砧板在左，生料必须跨区运输。

## 打法与分工（2P）

- 建议按区分工：玩家守左区（切菜 + 出餐），你守右区（煮饭 + 切黄瓜），双方在中转台交接。
- 也可以「一人专职切、一人专职煮」：米饭/虾从左箱取、运到右区加工；黄瓜从右箱取、运到左区切。
- 中转台是交接点：切好的料、煮好的饭放到中间台面，别让料停在原地。
- 据攻略，本关同样可先备料（第一道菜未出前不计时）。

## 陷阱与注意

- 生料跨区运输最易断供：黄瓜要送去左边切，切好的黄瓜/虾、煮好的饭要送回装盘。
- 出餐口在左区（占地 2 格竖），别跑到右区找。
