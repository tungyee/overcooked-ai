# 寿司城 1-4（主线 1-4）

> 本 AI 常驻主关卡。以下按 2P 双人分屏写，重点放在传送带走位、窄走廊与煮饭节奏——这些是实时快照读不出来、又最容易卡死 AI 的点。

## 元信息

- 关卡编号：`1-4`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：`Sushi_1_4`（双人版 `Sushi_1_4_2P`）
- 玩家数：2P

## 菜谱 / 订单

- 黄瓜寿司卷：海苔 + 熟寿司饭 + 切好的黄瓜。
- 鱼寿司卷：海苔 + 熟寿司饭 + 切好的鱼。
- 食材箱共 4 个（都在顶部）：海苔、鱼、寿司米、黄瓜。
- 工序：米 → 煮（BoiledSushiRice）；鱼 / 黄瓜 → 切；海苔直接取。装盘 = 海苔 + 熟饭 + 切好的鱼或黄瓜，出餐。

## 关卡机制 / 地形

- **两条地面传送带（自动步道）**：顶部一条向右移、底部一条向左移（速度约 2.5）。会推动站在上面的厨师和掉落在地的食材——**顺着方向走省时，逆着走吃亏**。
- **窄走廊**：中央一列柜台把厨房拦成左右两半，只有中间窄口可穿行，容易与玩家撞车。
- 布局（按仓库实测帧）：顶部一排 4 个箱子 + 2 个砧板；右侧 3 个灶台；左侧洗碗池 + 盘回收 + 垃圾桶；底部中间是出餐口与盘回收；中央台面初始有 4 个干净盘。
- 出餐口/盘回收在底部中间，洗碗池在左侧。
- 出生点：左上靠近海苔/米箱，右上靠近鱼/黄瓜箱与 2 个砧板。

## 打法与分工（2P）

- 推荐按「煮饭 / 切菜装盘」分工：
  - 一位负责米饭——从米箱取米 → 下右侧灶台煮 → 熟了盛出；顺带洗碗。
  - 另一位负责切鱼/黄瓜、取海苔装盘、接熟饭、送餐到出餐口。
- 流程顺序：**先煮米（最慢）**，煮米期间切鱼/黄瓜；饭一熟立刻配「海苔 + 熟饭 + 鱼/黄瓜」出餐；灶一空立刻补米，别让锅空着。
- 传送带走位：跨中线尽量顺着传送带方向走，别逆向顶带；掉落食材会被带滑走，别掉在带上。
- 初始 4 个干净盘够前几单，之后脏盘要回收到左下洗碗池洗。

## 陷阱与注意

- **饭糊锅**：煮饭要盯火，熟了立刻端走，否则烧糊起火。
- **窄走廊撞车**：两人同时过中央窄口会互相挡，建议一进一出、错峰通过。
- 本关有脏盘（需回收洗碗），别让脏盘堆积占用出餐节奏。
