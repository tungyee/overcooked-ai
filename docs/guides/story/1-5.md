## 菜谱 / 订单

- 番茄意面：熟意面 + 切好的番茄。
- 意面（Pasta）→ 入锅煮成熟意面（BoiledPasta）；番茄（PastaTomato）→ 切碎（ChoppedPastaTomato）。
- 装盘 = 熟意面 + 切好的番茄，出餐。

## 关卡机制 / 地形

- **热气球关卡，两块会动的部分**：
  1. **右侧篮子（气球吊篮）沿 z 轴水平漂移**：三个停靠位 TOP / MID / BOT（一个来回约 50 秒），篮子上挂着食材箱、洗碗池、盘回收等站点，随篮子漂移「时可达、时不可达」。
  2. **左侧主地板内，3 个砧板 + 垃圾桶整列上下移动**（周期约 56 秒，每次平移一格）：砧板位置会变，别按固定位置记。
- 两块地板之间始终相连（实测不必「等船」），但篮子漂走时上面的站点暂时够不到。
- 场景有「歪风」感，玩家/物品会被移动平台带着走。

## 打法与分工（2P）

- 本关难点在「囤菜」而非流程：番茄要切、意面要煮，但砧板和篮子都在动，别把料囤在会动的位置上。
- 建议分工：
  - P1（队友）守主地板：盯锅煮意面、趁砧板移动到可切位置时切番茄。
  - P2（你 / AI）负责跨篮子取料/送料、洗碗、回收脏盘（食材箱/洗碗池在篮子上，篮子漂到跟前时抓紧操作）。
- 先煮意面（煮比切慢）、再切番茄；据攻略本关同样可先备料（第一道菜未出前不计时）。

## 陷阱与注意

- **别把囤的菜放在移动砧板/篮子路径上**，会被带走甚至掉进垃圾桶。
- 篮子漂走时，其上的站点够不到——别在够不到时反复冲，等篮子漂回再操作。
- 锅里的意面要看着，煮糊会起火。
- 脏盘用完要洗（洗碗池在篮子上，趁篮子到位时洗）。
