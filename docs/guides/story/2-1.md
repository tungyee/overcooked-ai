## 菜谱 / 订单

- 快餐组合 `ChickenNuggetsAndChips`：**薯条**（土豆 → 砧板切成 `Chopped_Potato` → 炸锅炸成 `FriedChips`）与**鸡块**（`NuggetChicken` → 砧板切成 `NuggetChoppedChicken` → 炸锅炸成 `FriedChickenNuggets`）。
- 订单可能是单点一样，也可能两样都要；全程只有这两样，无其它工序。

## 关卡机制 / 地形

- **两块互不相连的地面**，只能靠**投掷**传料：厨房（静止）与木筏（`Raft_Top`，在 x/z 上漂移，速度约 1 m/s）。
- 厨房：土豆/鸡块两个料箱、两个炸锅、4 个盘子、盘回收口、垃圾桶、出餐口、灭火器。
- 木筏：两块砧板 + 一圈台面。木筏上的料会随筏漂移，砧板能直接接住投来的料。
- 投掷射程约 **7.5 m**；木筏南缘到炸锅约 9.6 m，从筏上投回厨房会落在炸锅前约 2 m 的地上，需由厨房侧捡起下锅。

## 打法与分工（2P）

- **开局 P2（你）在木筏、P1（队友）在厨房**，两人可达场交集为空，原料全靠 P1 从厨房投上筏。
- P1（厨房侧）：把土豆/鸡块**往木筏上扔**；接住 P2 扔回的切好的料下炸锅；盯好两口炸锅的熟度、盛盘出餐。
- P2（木筏侧）：把投上来的土豆/鸡块**切好**，立刻朝厨房炸锅方向投回；筏上随时保留待切料，避免空转。
- 节奏：P1 一次多扔几份原料上筏；P2 切完即扔回、不等攒满。快糊时优先把已熟料盛盘，别让炸锅烧穿。

## 陷阱与注意

- **原料不来 = 空转**：P2 够不着厨房两个料箱，唯一输入是 P1 的投掷，务必把「求 P1 扔原料」当成常驻动作。
- 投掷落点受木筏漂移影响，落在筏外的料会掉水里；切料投回时留出「捡起→下锅」的距离余量。
- 炸锅少（2 口）而订单密，糊锅/断供风险集中在厨房侧；P2 别把所有切料一次投回导致厨房台面堆满。
