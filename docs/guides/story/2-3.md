# 主线 2-3（热气球·双锅意面）

## 元信息

- 关卡编号：`2-3`
- 战役：主线
- 内部关卡名（插件 `level`）：`Balloon_2_3`
- 玩家数：2P

## 星级门槛（2P）

| 星级 | 分数 |
|---|---|
| 1★ | 220 |
| 2★ | 300 |
| 3★ | 400 |
| 4★ | 750 |

## 菜谱 / 订单

- **意面（Pasta）**：面条在**两口煮锅**里煮成 `BoiledPasta`；浇头多样——肉（`BurritoMeat`）、蘑菇切配后煎，海鲜（鱼 / 虾）切配后煎成 `PanFriedFish` / `PanFriedPrawns`。
- 常见组合：肉意面（`MeatOnly`）、蘑菇意面、海鲜意面 `Marinara`（鱼 + 虾）等；按订单取浇头。

## 关卡机制 / 地形

- 热气球关，两个厨师被分隔在两侧，靠投掷传料；**两口煮锅**是本关标志（对比 2-2 的单锅）。
- 底部有一个会左右移动的平台，把一侧做好的成品/半成品运到另一侧出餐。
- 出餐口在某一侧，组合好的意面要放到移动平台或投到出餐侧。

## 打法与分工（2P）

- 分工建议按「煮面侧 / 煎浇头侧」切：
  - 一侧：守煮锅煮面，把生面/切好的浇头料投给对面。
  - 另一侧：切配并煎肉/蘑菇/海鲜，接面后组装。
- 节奏跟着底部平台走：平台往一侧移时该侧**洗碗/囤料**，平台往另一侧移时该侧**煮面/煎肉**，否则赶不上这一波。
- 四星约需 10 道菜；初期按订单顺序做（前几单注意浇头组合），后期按「一份肉 + 一份蘑菇/海鲜」批量做。

## 陷阱与注意

- 盘子用完要有人专门洗；移动平台没到位的空档正好用来洗盘、切料。
- 两口煮锅都别闲着，但更要注意**快糊前先盛面**，糊锅损失整锅面条。
- 熟鱼/熟虾这类海鲜浇头做好后没盘装会触发救锅，别让煎锅烧穿。
