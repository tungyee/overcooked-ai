# 主线 2-5（矿洞·墨西哥卷）

## 菜谱 / 订单

- **墨西哥卷（Burrito）**：卷饼皮 `Tortilla` + 熟米饭 + 熟肉（`BurritoMeat` 切后煎）。米饭、玉米卷皮、肉三样轮番出现，做法与 2-4 一致。

## 关卡机制 / 地形

- 有**移动平台**周期性地把整组厨具/食材从一侧带到另一侧（「菜移到左边」的节奏），两侧角色要随平台轮换。
- 布局随平台移动而变化，不能长期固定站位。

## 打法与分工（2P）

- 节奏核心：**每当平台把厨具移到左侧，必须有人守在那煮饭、扔卷饼皮、扔肉**；另一个人切肉、煎肉、上菜，上完顺手洗碗，两人轮换。
- 做饭顺序：先煮米饭（耗时），肉切+煎并行；熟料齐卷起送餐。
- 四星约 9 单即可，节奏比 2-4 好掌控，重点是随平台轮换不空转。

## 陷阱与注意

- 平台移动造成「人都挤在一侧、另一侧无人」的空窗，要提前按平台节拍分配谁去哪边。
- 卷饼皮/肉/米都需要跨侧投掷，投偏掉坑会浪费约 5 秒复活时间。
