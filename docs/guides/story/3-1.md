## 菜谱 / 订单

- **披萨（Margherita 玛格丽特）**：面团 `Dough` → 砧板切成 `Pizza_Base_Raw`（饼底）→ 放上番茄 `Tomato`、芝士 `Cheese` → **整份进烤箱**烤成 `MargheritaPizza` → 盛盘出餐。
- 披萨是「整份进炉」的菜：进盘的是一个熟料节点（`cooked:cheese+dough+tomato:oventray`），不是三样分开的料。

## 关卡机制 / 地形

- **静态分割厨房**：开局 P2 被关在左侧小区（番茄箱、3 块干净盘、灭火器），P1 在右侧大区（面团/芝士箱、两台烤箱）；中间列有一块**双方都够得着的共享台面**（`countertop_01_standard_gold (20)`）。
- 阶段变化：**砧板整列滑动**到 x≈13.2 后，P2 的区扩到烤箱和三块板，P1 只剩面团/芝士一侧，共享台面消失。
- 有**两层楼**（`Left Side Stairs` 左楼梯连通），出餐口在二楼，需走楼梯。

## 打法与分工（2P）

- 开局（阶段 A）：P2（你）在左区**切番茄/备盘**，把干净盘通过共享台面传给 P1；P1 在右区切面团、放料、进烤箱。
- 阶段 B（砧板滑动后）：P2 够得着烤箱与砧板，转为切饼/放料/进炉；P1 专守面团+芝士料源。
- 关键分工：**面团/芝士在 P1 侧、番茄在 P2 侧、烤箱在 P1 侧（开局）**——披萨要整份进炉，饼底在谁侧就由谁负责放料进炉，另一侧把缺的料（番茄/芝士/盘）投或送到共享台面。
- 二楼出餐口要经左楼梯，端着成品别在楼下干等。

## 陷阱与注意

- 阶段切换后共享台面消失，**跨侧传料只剩投掷**；投偏会浪费时间。
- 生饼和熟披萨同名 `Pizza_Base_Raw`，别把生饼当熟披萨端走。
- 盘全在 P2 侧、烤箱全在 P1 侧（开局），盘没送过去就会「披萨出炉却没盘装」。
