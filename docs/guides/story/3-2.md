## 菜谱 / 订单

- **披萨（Margherita 玛格丽特）**：面团 `Dough` 切成 `Pizza_Base_Raw` 饼底，放番茄 `Tomato`、芝士 `Cheese`，整份进烤箱烤成 `MargheritaPizza`，盛盘出餐。
- 与 3-1 同一配方；本关注意点是「生饼与熟披萨同名」造成的取料混淆。

## 关卡机制 / 地形

- **地图左右分割**，P2 在右半区；中间有一道**移动墙**（动墙）会周期性改变两侧的通行/隔断状态。
- 左侧有食材与砧板，中间是盘子和锅/烤箱，右侧（P2 侧）是出餐方向。
- 两侧料源不对称：面团 P1 侧更近（P1≈1 步 vs P2≈3 步），番茄/芝士则偏 P2 侧。

## 打法与分工（2P）

- 分工按料源就近：**面团交给 P1 切**，番茄/芝士由 P2 切并放料；饼底/半成品跨侧用投掷或移动墙开口时递送。
- P2（你）在右半区：切番茄/芝士、把饼底补料、整份送进烤箱、盛盘出餐。
- P1（队友）：切面团成饼底，把生饼投/送到 P2 侧，接缺料。
- 移动墙隔断时别硬闯，等开口或改用投掷；墙把半成品隔在两侧是最常见的卡点。

## 陷阱与注意

- **生饼抢走熟披萨的可达性**：场上同时有生 `Pizza_Base_Raw`（砧板/烤箱里）与熟披萨时，别把生饼当成品端走。
- 移动墙会把只放了一半料的饼隔到另一侧，导致「有料补不了、有炉进不了」，尽量在墙开口时把半成品送到烤箱侧。
