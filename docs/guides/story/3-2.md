## 菜谱 / 订单

- 汉堡（BeefBurger 系列）：面包 Bun + 煎肉排 FriedMeat（肉 Meat → 切 → 煎锅 FryingPan 煎熟）。
  - 牛肉汉堡 BeefBurger = Bun + FriedMeat
  - 芝士汉堡 BeefBurgerCheese = Bun + Cheese + FriedMeat
  - 芝士生菜汉堡 BeefBurgerWithGreensNCheese = Bun + FriedMeat + Lettuce + Cheese
- 肉排要**切片再煎**（两步，最耗时）；生菜、奶酪都需切；面包直接取用。

## 关卡机制 / 地形

- 左右两侧有**魔法镜子**，可瞬移到另一侧；中间的**梯子 / 隔断会周期性变换位置**。
- 布局：左边食材 + 砧板，中间盘子和煎锅，右边出餐口。
- （机制描述来自公开攻略，待实机核实。）

## 打法与分工（2P）

- 肉最耗时（切片 + 煎炸两步），建议固定一名厨师（P1）专职**切肉 + 煎肉**；另一名（P2）切生菜、切奶酪并组装汉堡。
- 用投掷把左边切好的料传到中间；中间厨师在煎肉间隙完成组装 + 装盘。
- 用魔法镜子左右快速移动，别绕路硬跑。

## 陷阱与注意

- 中间梯子 / 隔断变换时会把厨师和煎锅隔开，煎肉时别离锅太远，防止糊锅救不了。
- 盘子用光后要及时安排洗碗，否则菜做好了没盘装。
