## 菜谱 / 订单

- **披萨（Pizza）**：切好的食材组装到饼底上，整份放进**烤箱**烤熟。烤箱在左下角与右下角各一台。

## 关卡机制 / 地形

- 中间有一张**会变换（旋转/平移）的桌子**，会把厨师与烤箱/食材分隔开；桌子横向时两侧分上下，纵向时分左右。
- 布局随中间桌子变换而变化，换阵型期间拿不到食材。

## 打法与分工（2P）

- **两人必须始终分处中间桌子两侧**：桌子横向时一人上一人下，纵向时一人左一人右。
- 分工建议：
  - 布局上下时，一侧主要负责洗盘子 + 送烤箱，另一侧负责切菜 + 组装 + 上菜；
  - 布局左右时，一侧负责上菜 + 送烤箱 + 切菜/组装，另一侧负责切菜/组装 + 送烤箱 + 洗盘子。
- 开局前两道菜**同时最快速度上菜**，让后续脏盘成对出现，省下送洗时间。
- 阵型固定时适当多扔几个食材囤着，换阵型期间拿不到食材就不会断供。
- 四星约需 14 道菜（13 道偏悬）；最后 30 秒只需开始做最后一道，不再多余取料切菜。

## 陷阱与注意

- **洗盘子和送烤箱是瓶颈**：脏盘及时洗、烤箱别长时间闲置。
- 进烤箱后别乱走，否则中间变换的桌子会把厨师与烤箱隔开，眼看着烤箱着火也无能为力。
- 盘子用光前就要分一人专门洗碗，否则「菜做好了没盘装」。
