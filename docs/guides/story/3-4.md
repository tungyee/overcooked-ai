## 菜谱 / 订单

- **汉堡（Burger）**：汉堡胚 `Bun` + 煎熟的肉饼（肉切配后煎）。肉是唯一复杂工序，直接影响效率。

## 关卡机制 / 地形

- 可借助**魔法镜子**在左右两侧瞬移，快速往返。
- 布局：**左侧是砧板和锅，右侧是食材和水池**；肉在左侧加工，加工好的肉**不能直接投掷**，必须经魔法镜子送过去。
- 建议把食材统一集中到中间，右侧负责组装成品。

## 打法与分工（2P）

- 分工按「加工侧 / 组装侧」：
  - 右侧的人：从右侧取食材投到左侧，守中间台面**组装汉堡 + 上菜**。
  - 左侧的人：切肉 + 煎肉，把煮好的肉放到中间台面（锅不必一直守着，下次路过再带走）。
- 两人都要善用魔法镜子移动，才能到最佳效率。
- 汉堡胚可以直接扔给另一个人上菜。

## 陷阱与注意

- **加工好的肉不能直接投掷**，务必走魔法镜子/中间台面，硬投会落地失效。
- 肉的加工是瓶颈，多花心思切/煎肉，比抢着组装更影响总效率。
- 魔法镜子是双向门，传完别转身走回门口被再次传走。
