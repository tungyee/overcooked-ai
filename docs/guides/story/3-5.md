# 主线 3-5（木筏·炸鸡薯条）

## 元信息

- 关卡编号：`3-5`
- 战役：主线
- 内部关卡名（插件 `level`）：`Rapids_3_5`
- 玩家数：2P

## 星级门槛（2P）

| 星级 | 分数 |
|---|---|
| 1★ | 240 |
| 2★ | 300 |
| 3★ | 420 |
| 4★ | 850 |

## 菜谱 / 订单

- **快餐组合**：**鸡块**（鸡肉 → 砧板切 → 炸锅炸成鸡块）与**薯条**（土豆 → 砧板切 → 炸锅炸成薯条），单点或组合。
- 有炸薯条/炸鸡的炸篮（`FrierBasket`）离火后放在台面上待盛。

## 关卡机制 / 地形

- **木筏关**：两个木筏相对独立，盘子在没有出餐口的那个木筏上；**出餐口在一只会上下晃动的「出餐船」上**，出餐口并非固定在网格上。
- 两个木筏并排（或上下并行）时才能端着成品走过去/投过去。
- 只有 **2 个盘子**，基本是「上一单、洗一单」的节奏。

## 打法与分工（2P）

- 用投掷即可过关；难点只在**盘子位置和送餐时机**。
- 分工建议动态：开局一人切菜备料、一人煮/炸/上菜；木筏移动后**谁离灶近谁看火、谁离砧板近谁切**，别死守固定角色。
- 盘子只有 2 个：一人端脏盘去洗 + 上菜时，另一人切料；洗完再切下一单，别切太多压盘子。
- 上菜口在右侧、木筏并排时（例如剩 3 分钟 ~ 剩 1 分 50 秒之间）抓紧送餐；两端木筏贴近时冲刺过去。

## 陷阱与注意

- **出餐船上下晃**：出餐口可达性随船位变化，端着成品却判「出餐口不可达」时，先把盘放木筏、等船回到可达位再送。
- 盘子紧缺，脏盘不洗就断供；四星约需 12~13 单。
- 投偏/落水会损失时间；掉进黑色水池会被吞噬。
