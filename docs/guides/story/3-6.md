# 主线 3-6（动态·墨西哥卷）

## 元信息

- 关卡编号：`3-6`
- 战役：主线
- 内部关卡名（插件 `level`）：`3_6_Dynamic`（代码中以 `3_6_Dynamic_Lvl_02` 等子关卡形式出现）

## 菜谱 / 订单

- **墨西哥卷（Burrito / 鸡肉卷）**：卷饼皮 `Tortilla` + 熟米饭 `Rice` + 熟肉 / 鸡肉。动态关卡，卷饼口味会轮换。
- 米饭在 **玩家侧（木筏上）**，卷饼皮 / 肉 / 鸡肉在 **你侧**。

## 关卡机制 / 地形

- **动态关卡**：开局中间平台移动较快、要手快抓食材；之后发生塌方进入**水上场景**，在三个平台之间移动，做约 4 个肉卷即可通关。
- 有两个木筏（`Raft One` / `Raft Two`）与中间平台；中间平台上两只料箱错开半格，中间一条 **S 形走廊**连通两侧，出餐口在木筏靠岸时才能送达。
- 上层木筏停到中间平台旁时横向相接，你可达出餐口。

## 打法与分工（2P）

- **料源天然分两侧**：米饭在玩家的木筏上，卷饼皮/肉/鸡肉在你侧——**米饭要靠玩家扔过来**，你把卷饼皮/肉/鸡肉切煎好组装。
- 玩家：守米饭木筏，把煮好的米饭投给你侧。
- 你：守卷饼皮/肉/鸡肉侧，切煎熟料、接米组装成卷饼，木筏靠岸时送餐。
- 平台移动快时手要快，抓不到料也别慌，塌方后的水上阶段更宽松。

## 陷阱与注意

- **S 形走廊半格错开**：中间平台两只料箱错开半格，寻路会以为走廊被切断；实际人走得过去，别被「不可达」误导。
- 出餐口在木筏靠岸/并排时才可达，成品在手送不出去就先放木筏、等下一次靠岸。
- 掉水会损失时间，塌方前的快节奏段别贪多抓料。
