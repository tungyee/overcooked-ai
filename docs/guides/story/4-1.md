## 菜谱 / 订单

- 寿司：
    海苔 + 熟米饭 + 鱼/黄瓜（切鱼/黄瓜 → 煮饭 → 装盘/卷）。
    生鱼片
    生虾片
- 关键点：**鱼、虾在马路对面**，取鱼、虾必须穿过有车辆穿行的马路。
- 中后期会插入「单一菜谱」的简单订单（如鱼切片即上的刺身），时间紧时优先做这类单赚小费。

## 关卡机制 / 地形

- 中间是一条马路，有红绿灯和驶过的汽车：过马路要看灯，灯色不对时会被汽车撞飞（来源表述为「红灯行、绿灯停」，与日常交通相反，以关卡实际灯色为准）。
- 马路把厨房分成两半：一侧备菜、一侧煮饭/组装，鱼被隔在对侧。

## 打法与分工（2P）

- 备菜区的人：切黄瓜、取海苔、开煮米饭。
- 对侧（鱼虾区）的人：取鱼、切鱼、取虾、切虾；不在路口停留挡道。
- 节奏：寿司的瓶颈是米饭，尽早开煮；切好的鱼/黄瓜先备着，等饭熟即组装。后期简单单优先抢。

## 陷阱与注意

- 抢过马路被车撞 → 掉单 + 复活耗时，务必看灯。
- 饭煮糊或鱼断供会断连击，米饭要有人盯。
