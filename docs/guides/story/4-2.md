## 菜谱 / 订单

## 关卡机制 / 地形

- 两个竹筏相互独立、各自沿水路漂移，厨师**无法进入对方的竹筏**。
- 两边各有一条 L 形**台面传送带**（`ConveyorStation`）：段在竹筏上、人走不上去，物料放上去会沿带子走；两筏靠近时，接口段的带子相接，物料跨水送到对面。
- 你这侧（Raft Two）：两个炸锅、一块砧板、生菜/番茄料箱、洗碗池、沥水架；玩家那侧（Raft One）：土豆/鸡块料箱、两块砧板、盘堆、出餐口。
- 生食材和**切好的料**都可以直接投掷过水；只有**放在盘子上的成品/盘子不能扔**，才走传送带。
- 四周是黑色水池，掉进去会被吞噬（死亡）。

## 打法与分工（2P）

- 你（AI）：待在**炸锅 + 洗碗池那一侧**（Raft Two）。接对面送来的土豆/鸡块 → 炸 → 装盘；生菜/番茄料箱也在这侧，沙拉的切配和组装可以自己做完。
- 玩家（人类）：待在**土豆/鸡块料箱 + 出餐口那一侧**（Raft One）。切土豆、切鸡块，切好直接扔过来（切好的料可以扔）。
- 送餐口在你的对面：你装好的成品盘走**传送带**交给玩家上菜，不要端在手里等。
- 如果你这局没法自己装盘/送餐，切好的生菜、番茄直接扔给玩家，不要放传送带，也不要一直留在自己砧板上。
- 脏盘：洗碗池在你这侧，玩家会把脏盘送过来；送到就优先洗，别让它被传送带带进垃圾桶。干净盘从你这侧传回去。
- 分工建议按物料拆分「切」：`Potato` / `NuggetChicken` 归玩家，`Lettuce` / `Tomato` 归你；`cook`、`plate` 归你。不要把所有动作都塞给玩家，否则两边都断料。

## 陷阱与注意

- 不要靠近竹筏边缘的黑色水池，冲刺/对撞容易把人带下去。
- 传送带只运**不能扔**的东西（装好菜的成品盘、干净/脏盘）。放料固定放**带子开头那一段**（L 形柱子的顶端），不要放到远端工作区——那里是死胡同，对面拿不到。
- 投掷可以用于生料和切好的料；装盘后的成品不能扔，只能走传送带。
- 扔料时避开垃圾桶：直线从桶上方过会被桶接住，料就没了；被挡时换一个出手点再扔。
