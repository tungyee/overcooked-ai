# 流水线汉堡坊（主线 4-3）

## 元信息

- 关卡编号：`4-3`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P

## 菜谱 / 订单

- 汉堡：汉堡面包 + 煎肉排（肉切片 → 煎）+ 可选生菜/番茄/奶酪（切好直接叠，无需再加热）。
- 只要做约 4 个汉堡即可通关；冲星才需要赶单。

## 关卡机制 / 地形

- 上下两条**单向传送带**是主要移动手段：顺方向会被带走，逆行无法前进，厨师在两侧移动通常要绕一圈。
- 布局：左侧食材 + 水池，中间锅（煎肉），右侧砧板。
- 传送带上不要加速冲刺，控制方向即可，否则容易掉下去。

## 打法与分工（2P）

- 开局：两个厨师先把两片肉经传送带送到右侧切片。
- P1（队友）：留在中间煎肉、翻面，别让肉糊。
- P2（你 / AI）：回左侧做面包/配菜组装，通过中间小桌拿熟肉。
- 节奏：不要把人固定死在一个区，灵活换位；每 2 个汉堡为一组做，避免一盘糊一盘断。

## 陷阱与注意

- 传送带逆行/加速易掉下去。
- 煎肉要盯火候，煮糊直接报废；右厨师贴边走时注意别掉下传送带。
