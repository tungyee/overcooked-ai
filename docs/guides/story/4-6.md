# 矿车卷饼线（主线 4-6）

## 元信息

- 关卡编号：`4-6`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：未知

## 菜谱 / 订单

- 卷饼（墨西哥卷）：面饼 + 熟米饭 + 切好并煎好的肉/蘑菇/鸡。
- 米饭和生食材加工不难；难点在组合时要跨传送带绕一圈。

## 关卡机制 / 地形

- 食材箱、砧板等道具放在**矿车**上，矿车会移动，导致食材和砧板位置经常变化。
- 上下两条**单向传送带**（逆行无法前进），厨师在两侧移动通常要绕一大圈。
- 偶尔掉落零散火球，只是干扰，可以不管、专心做菜。

## 打法与分工（2P）

- 玩家：煮米饭 + 切/煎肉。
- 你：另一侧切肉、装面饼、组合卷饼。
- 组合时两个厨师必须靠传送带绕一圈汇合，提前把料放传送带送过去，减少往返。

## 陷阱与注意

- 矿车移动会改变食材/砧板位置，别死记固定坐标，以快照实际位置为准。
- 单向传送带逆行走不动，别逆行浪费时间。
- 火球只挡路不伤线，别为了躲火球打乱做菜节奏。
