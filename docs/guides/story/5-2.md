# 热气球豪华汉堡（主线 5-2）

## 元信息

- 关卡编号：`5-2`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P

## 菜谱 / 订单

- 汉堡，共四种，共性都是「汉堡面包 + 肉排」，再叠加不同配料：
  - 面包 + 肉排（基础）
  - 面包 + 奶酪 + 肉排
  - 面包 + 生菜 + 番茄 + 肉排（豪华）
  - 面包 + 生菜 + 奶酪 + 肉排

## 关卡机制 / 地形

- 中间桌子把关卡分割开，**加工过的食材只能通过中间单个小格的桌子**传递。
- 最左边是出餐口。
- 天上不断掉**火球**，会阻挡移动；后期火球特别密集，要预判落点。

## 打法与分工（2P）

- 肉排侧的人：切肉、煎肉、洗盘、递汉堡面包。
- 出餐口侧的人：灭火、切配菜（生菜/番茄/奶酪）、上菜。
- 节奏：前期把食材做好送到左边，再把灭火器也送到左边（左区火球多，且后期以组合和运送为主）。
- 火球掉落有规律，熟悉后可以卡点绕行。

## 陷阱与注意

- 火球挡路是最大干扰，灭火器留在左区备用。
- 中间单格桌是唯一运输通道，别堵住。
- 煎肉要盯火候，肉糊则整单报废。
