# 魔法塔汉堡（主线 5-5）

## 元信息

- 关卡编号：`5-5`
- 战役：主线
- 内部关卡名（插件 `level`，若已知）：`Wizard_5_5`
- 玩家数：2P

## 星级门槛（2P）

| 星级 | 分数 |
|---|---|
| 1★ | 280 |
| 2★ | 360 |
| 3★ | 480 |
| 4★ | 1000 |

## 菜谱 / 订单

- 汉堡：汉堡面包 + 煎肉排 + 生菜/番茄/奶酪（切好直接叠）。
- 生菜、面包在**楼上**，肉排在楼下，存在高度差，需要把生菜/面包送下楼（或投掷）才能组合。

## 关卡机制 / 地形

- 中间长条桌把关卡分成两大区域；四个独立平台又分成四个小区，由**两个可操纵平台**连接。
- 两个平台的按钮与对应平台呈**对角线**关系。
- 多楼层：两座**楼梯会沉到地下再升起**，平面位置不变；二楼比一楼高一截（实测高差约 2.0），从一楼往二楼投肉会撞楼梯弹回。
- 隐藏技巧：当小平台停在左右两侧切菜/洗碗处时，上下两个平台处于可连接状态，可自由上下移动。

## 打法与分工（2P）

- 楼上的人：切生菜/番茄、把面包和生菜送下楼；必要时把料投下楼。
- 楼下的人：煎肉、组合汉堡，接楼上传下来的料。
- 组合一般在**中间长条桌**进行，组合好送到左边的窗口。
- 节奏：每轮做 2 道菜；移动浮板前一定等对方切完/洗完，否则会把对方卡住或挤下去。

## 陷阱与注意

- 高度差投掷是本关最大的坑：低处往高处砧板投料会弹回，改为先送上楼再操作。
- 楼梯会升降，走在楼梯上要留意脚下，别掉进缝隙。
- 按钮与平台对角关系易记错，移动前先确认动的是哪个平台。
