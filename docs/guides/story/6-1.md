# 6-1（主线 · 不死面包 世界 6）

## 菜谱 / 订单

- 蛋糕（Cake）：鸡蛋 + 面粉 → 搅碎机打成面糊 → 进烤炉烤成蛋糕 → 装盘。
- 可选配料：巧克力。巧克力必须**先切碎**才能下料。

## 关卡机制 / 地形

- 左侧一条传送带（本关用处不大）。
- 中间有「会喷火球」的机关：火球落点有规律，会**扎堆**落在上方烤炉旁和下方搅碎机旁，堵住关键站点，需用灭火器及时扑灭。
- 右侧是出餐口。
- 灭火器用完建议放在中间桌上，方便下次随手拿。

## 打法与分工（2P）

- 搅碎机侧的人：取料 + 切巧克力，把鸡蛋/面粉送进搅碎机打糊。
- 烤炉侧的人：看烤炉（出炉、装盘、送餐），同时盯火球、用灭火器扑灭堵路火点。
- 流程顺序：先多打几份面糊囤在烤炉旁；火球一灭就立刻过去操作烤炉/搅碎机，别在火球区逗留。
- 投掷点：从切菜区把切好的巧克力或面糊直接投到搅碎机/烤炉旁，省往返。

## 陷阱与注意

- 火球会堵在烤炉和搅碎机旁，**先灭火再操作**，别硬凑。
- 巧克力没切碎不能下料。
- 灭火器别乱丢；用完放回中间桌，避免下次找不到。
