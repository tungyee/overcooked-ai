# 6-3（主线 · 不死面包 世界 6）

- 关卡编号：`6-3`
- 战役：主线
- 内部关卡名（插件 `level`）：未知（世界 6 为动态关，插件按 `1_6_Dynamic_*` 命名）

## 菜谱 / 订单

- 蛋糕类（搅碎 + 烘烤，与 6-1 相同流程：鸡蛋 + 面粉打糊 → 烤炉烤）。

## 关卡机制 / 地形

- 外圈传送带上放食材；四角站点：左上搅碎机、右上烤炉、左下砧板、右下锅（煎锅）。
- 两个按钮（上/下）切换传送带方向：**绿色按钮控左边传送带，蓝色按钮控右边传送带**。
- 按钮按下后有冷却时间，冷却期内锁定、不能连按。

## 打法与分工（2P）

- 左下砧板的人：切料，兼管传送带按钮。
- 左上搅碎机/右上烤炉的人：打糊、出炉、装盘、送餐。
- 流程顺序：利用外圈传送带把食材送到对应角落；按需切换方向把面糊/成品运到位。
- 投掷点：可从传送带把食材直接投到搅碎机/烤炉，省走路。

## 陷阱与注意

- 按钮有冷却，别乱按；方向错了会绕远路、浪费时间。
- 外圈传送带方向是关键，误判方向会导致食材送错角落。
