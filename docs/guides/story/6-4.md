# 6-4（主线 · 不死面包 世界 6）

- 关卡编号：`6-4`

## 菜谱 / 订单

- 汉堡（Burger）+ 披萨（Pizza）。
- 汉堡流程更简单，后期优先做汉堡冲分。
- 披萨：面团 + 配料（奶酪/番茄/蘑菇/辣肠/鸡等，切好）→ 烤箱烤。

## 关卡机制 / 地形

- 中间大平台是加工区；食材放在**两个可移动小平台**上，两个按钮控制小平台移动。
- 开局时小平台上一排食材拿不到，需按按钮把小平台移到最下面；移动过程耗时。

## 打法与分工（2P）

- 开局先把小平台停在合适位置，把下面一排食材**每样各拿 2 份**囤到大平台，再移动平台去拿上面一排（同样各拿 2 份）。
- 有了囤料后效率大增；洗盘空档由另一名厨师去按按钮调平台。
- 分工：一人守汉堡线（面包 + 熟肉），一人守披萨线（面团 + 配料 + 烤炉）；后期两人都转向汉堡。
- 投掷点：小平台上的食材可直接投到大平台加工区，省往返。

## 陷阱与注意

- 平台移动耗时，频繁调平台会断供；**先囤料再移动**。
- 别等食材用完才想到囤；注意洗碗节奏，避免没盘子。
