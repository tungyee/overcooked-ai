# 海滩 1-1（Surf 'n' Turf 1-1）

> DLC 第一关，冰沙入门。核心是水果切块 → 搅拌机，以及穿过厨房的康加舞人群。

## 菜谱 / 订单

- 草莓冰沙：草莓切块 → 搅拌机。
- 香蕉冰沙：香蕉切块 → 搅拌机。
- 本关只有这两种最基础的冰沙，无组合款。

## 关卡机制 / 地形

- **搅拌机（blender）**：冰沙的核心设备，切好的水果投进去搅拌。
- **康加舞人群（conga line）**：一条舞者队伍周期性穿过两个工作区，把入口挡住，厨师要等队伍过去才能穿行。
- **计时机制**：倒计时在**首次上菜后**才开始走，开局可以先囤料（来源：NovArcan）。

## 打法与分工（2P）

- 玩家：负责切水果（草莓/香蕉）→ 投进搅拌机搅拌。
- 你：接搅拌好的冰沙装盘、送餐，顺带回收脏盘。
- 流程：开局倒计时不走，先切一批水果囤在砧板旁；搅拌机别空着，出一杯补一杯；康加舞人群过来时提前站位，别被堵在搅拌机和出餐口之间。

## 陷阱与注意

- 康加舞人群挡路：切菜/送餐路线被切断时宁可等一秒，也别和玩家在窄口对撞。
- 切好的水果堆在砧板上会被后续订单打乱，按订单先切、先搅，别一次囤太多。
