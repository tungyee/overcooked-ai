# 海滩 1-2（Surf 'n' Turf 1-2）

> 全部冰沙款式登场，承载食材和砧板的平台会沉入水中再浮出，走位是关键。

## 菜谱 / 订单

- 草莓冰沙：3 个草莓 → 搅拌机。
- 香蕉冰沙：3 个香蕉 → 搅拌机。
- 西瓜冰沙：3 个西瓜 → 搅拌机。
- 香蕉菠萝冰沙：2 个香蕉 + 2 个菠萝 → 搅拌机。
- 全料冰沙：香蕉 + 西瓜 + 草莓 + 菠萝 → 搅拌机。
- 工序统一：水果切块 → 搅拌机 → 装盘出餐。

## 关卡机制 / 地形

- **下沉平台**：放食材箱和砧板的平台会周期性地沉入水中，再从别的位置浮出（来源：Game Craves）。
- 平台下沉会把上面的人和掉落物一起带走，别把切好的水果留在会沉的平台上。

## 打法与分工（2P）

- P1（队友）：盯住食材箱所在平台，趁浮出时切水果，投给搅拌机。
- P2（你 / AI）：守搅拌机与出餐口，接水果搅拌、装盘、送餐，回收脏盘。
- 流程：切 → 投 → 搅 → 出餐的单向流水线；平台浮出的空档里集中投料，平台下沉前撤离。

## 陷阱与注意

- 站在会沉的平台上会连人带菜一起掉进水里，白白浪费时间；投掷可以让你不登台就取/送料。
- 全料冰沙要 4 种水果，别把单款水果全搅掉，留出组合款需要的量。
