# 海滩 1-3（Surf 'n' Turf 1-3）

> 汉堡关，也是本 DLC 首次引入「水枪」洗盘的一关。厨房被分成两半，各管一组食材。

## 元信息

- 关卡编号：`1-3`
- 战役：Surf 'n' Turf
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P

| 星级 | 分数 |
|---|---|

## 菜谱 / 订单

- 原味汉堡：肉排煎熟 + 汉堡胚。
- 芝士汉堡：煎肉排 + 汉堡胚 + 切好的奶酪。
- 双层汉堡：2 块煎肉排 + 汉堡胚 + 切好的菠萝（本 DLC 特有）。
- 芝士生菜汉堡：芝士汉堡基础上加切好的生菜。
- 巨无霸汉堡：原味汉堡基础上加切好的生菜和番茄。
- 工序：肉排切+煎，配菜切，最后汉堡胚直接当「盘子」叠料。

## 关卡机制 / 地形

- **分隔厨房**：厨房被分成左右两半，各有一套食材箱和设备，两边不能直接走过去，靠投掷或中间传递（来源：Game Craves）。
- **水枪（Water Gun）**：本关起用于清洗脏盘，替代部分水池职能；拿水枪对准脏盘喷水即可洗净。
- 水枪也是 DLC 通用灭火工具。

## 打法与分工（2P）

- P1（队友）：守一侧负责煎肉排 + 切配菜（奶酪/生菜/番茄/菠萝）。
- P2（你 / AI）：守另一侧接肉排和配菜，用汉堡胚组装、送餐，并用水枪洗盘。
- 流程：两侧同时备料 → 投掷到组装侧 → 组装侧叠汉堡出餐；脏盘及时喷洗，别断盘。

## 陷阱与注意

- 汉堡胚可以直接当容器叠料（不用等盘子），但成品仍需盘子出餐，盘子周转是本关瓶颈。
- 水枪占一个身位且要停下来喷，别在出餐高峰时让洗盘占满 AI 的时间。
