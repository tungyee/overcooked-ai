# 海滩 1-4（Surf 'n' Turf 1-4）

> 世界 1 收官冰沙关：两片水池之间只有一条窄走道，载食材的平台左右来回移动。

## 元信息

- 关卡编号：`1-4`
- 战役：Surf 'n' Turf
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P

| 星级 | 分数 |

## 菜谱 / 订单

- 与 1-2 相同的全部冰沙：草莓 / 香蕉 / 西瓜 / 香蕉菠萝 / 全料冰沙。
- 工序：水果切块 → 搅拌机 → 装盘出餐。

## 关卡机制 / 地形

- **窄走道分隔**：厨房被两个水池夹出一条窄走道，两侧都要过这条走道，容易撞车（来源：Game Craves）。
- **移动食材平台**：放食材箱的平台沿池边左右来回移动，取料要等平台靠近。

## 打法与分工（2P）

- 玩家：跟着移动平台走，趁平台靠近时切水果，投给搅拌机。
- 你：守搅拌机 + 出餐口，接料搅拌、装盘、送餐。
- 流程：切 → 投 → 搅 → 出餐；移动平台靠到哪边，哪边优先取料，投掷代替登台。

## 陷阱与注意

- 窄走道是唯一陆路，两人同时过会堵死，建议一进一出错峰。
- 切好的水果别留在移动平台上，会被带离搅拌机，白切一场。
