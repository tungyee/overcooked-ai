## 菜谱 / 订单

- 烤肉串（肉串）：竹签 + 肉排 → 烧烤架烤。
- 鸡肉串：竹签 + 鸡肉 → 烧烤架烤。
- 蔬菜串：竹签 + 蔬菜 → 烧烤架烤。
- 工序：食材切好 → 串上竹签 → 放烧烤架烤 → 装盘出餐。具体每种串的食材数量以实机菜单为准（待核实细节）。

## 关卡机制 / 地形

- **烧烤炉 + 鼓风机**：烧烤架的火会随时间变弱，需用鼓风机吹火维持温度，否则肉串烤不熟/烤糊。
- **水枪洗碗**：脏盘用水枪喷洗，本关无传统水池，洗碗靠水枪。
- **计时机制**：倒计时在首次上菜后开始（来源：NovArcan）。

## 打法与分工（2P）

- 玩家：切肉/蔬菜 → 串竹签 → 上烧烤架，顺手用鼓风机维持火。
- 你：看火、翻串/取熟串装盘出餐，并用水枪洗盘。
- 流程：开局先囤一批切好的料；烧烤架别空着，火弱立刻吹；盘子要跟上出餐节奏。

## 陷阱与注意

- 火灭 = 全队停摆，鼓风机要有人专盯，别两人都埋头切菜。
- 肉串烤过头会烧糊起火，熟了立刻取走；起火用水枪灭火。
