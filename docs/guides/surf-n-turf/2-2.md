# 海滩 2-2（Surf 'n' Turf 2-2）

> 烤肉串关，同时也是凯文（隐藏）关的解锁关：120 秒内上第一单 + 结束时至少 1 星。

## 元信息

- 关卡编号：`2-2`
- 战役：Surf 'n' Turf
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P
- 解锁凯文关条件：本关开始后 **120 秒内提交第一个订单**，并且结束时获得 **≥1 星**

## 星级门槛（2P）

| 星级 | 分数 |
|---|---|
| 1★ | 360 |
| 2★ | 480 |
| 3★ | 600 |
| 4★ | 720 |

## 菜谱 / 订单

- 烤肉串（鸡肉串 / 肉串 / 蔬菜串），与 2-1 相同的烧烤流程。
- 具体串型组合以实机菜单为准（待核实细节）。

## 关卡机制 / 地形

- 烧烤炉 + 鼓风机维持火、水枪洗盘，与 2-1 一致。
- 本关是凯文关解锁关，追求四星之外还要注意开局速度。

## 打法与分工（2P）

- 玩家：切料 + 串串 + 烧烤架。
- 你：看火 + 出餐 + 水枪洗盘。
- 流程：开局先快速备好第一单材料，赶在 120 秒内出第一单（解锁凯文）；之后按正常烧烤节奏维持火和盘子。

## 陷阱与注意

- 解锁条件要求「120 秒内第一单」+「≥1 星」，不要为了四星拖开局，先保第一单速度。
- 火灭和盘子断供仍是主要断点，鼓风机和水枪要有人盯。
