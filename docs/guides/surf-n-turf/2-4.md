## 菜谱 / 订单

- 原味蛋糕：面粉 + 鸡蛋 + 切好的蜂蜜 → 搅拌 → 烤箱烤。
- 巧克力蛋糕：在原味基础上加切好的巧克力。
- 胡萝卜蛋糕：在原味基础上加切好的胡萝卜。
- 工序：切配 → 搅拌机搅成蛋糕糊 → 连搅拌容器一起进烤箱烤 → 装盘出餐（烤完记得取出容器）。

## 关卡机制 / 地形

- **中间传送带**：两侧之间靠传送带传递食材/蛋糕（来源：bilibili 2-4 描述）。
- **交界口 / 垃圾口交接**：洗好的盘子放交界口附近，接到烤好的蛋糕转身就能装盘（来源：bilibili 双人挑战视频）。
- 搅拌机在左侧更顺，从右侧斜扔容易误扔进搅拌容器。

## 打法与分工（2P）

- 玩家：切蜂蜜/巧克力/胡萝卜 + 搅拌成蛋糕糊，经传送带传给烤箱侧。
- 你：接蛋糕糊进烤箱、看火、烤熟装盘出餐，并回收洗盘。
- 流程：左侧集中搅拌（原味尽量在左侧搅），盘子预置在交界口附近；蛋糕一出烤箱立刻装盘，搅拌容器及时还回搅拌机。

## 陷阱与注意

- 蛋糕和松饼原料几乎一样，区别在「有蜂蜜进烤箱」；搅拌错了整碗报废，只能倒垃圾桶。
- 烤熟的蛋糕在烤箱里太久会烧糊，熟了立刻取。
