# 海滩 3-1（Surf 'n' Turf 3-1）

> 世界 3 开头，回到烤肉串：鼓风机维持火 + 全场只有两个盘子，洗盘节奏是命门。

## 菜谱 / 订单

- 烤肉串（鸡肉串 / 肉串 / 蔬菜串）。
- 工序沿用 DLC 烧烤流程：切料 → 串签 → 烧烤架烤 → 装盘出餐。

## 关卡机制 / 地形

- **鼓风机维持火**：烧烤炉需持续吹火（来源：bilibili「记得吹吹」）。
- **盘子极少**：全场只有两个盘子，脏盘必须及时水枪清洗，否则出餐断供。
- 水枪洗盘是本关瓶颈。

## 打法与分工（2P）

- 玩家：切料 + 串串 + 烧烤 + 鼓风机。
- 你：看火取熟串、装盘出餐，并紧盯两个盘子的清洗周转。
- 流程：两个盘子「出餐 → 回收 → 喷洗 → 再装」闭环不能断；火弱立刻吹，别让烧烤架空转。

## 陷阱与注意

- 盘子只有两个，一旦两个都脏着且没人洗，熟串出不去，直接断连。
- 火灭同样致命，鼓风机和水枪都要有人盯，建议 你主管这两个动作。
