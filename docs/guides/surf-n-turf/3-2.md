# 海滩 3-2（Surf 'n' Turf 3-2）

> 「天灾人祸」关：火会到处冒出来，一边灭火一边吹烧烤炉，全程高压。

## 元信息

- 关卡编号：`3-2`
- 战役：Surf 'n' Turf
- 内部关卡名（插件 `level`，若已知）：未知
- 玩家数：2P

| 星级 | 分数 |
|---|---|
| 1★ | 360 |
| 2★ | 480 |

## 菜谱 / 订单

- 烤肉串（鸡肉串 / 肉串 / 蔬菜串）。
- 工序沿用烧烤流程，但全程被火打断。

## 关卡机制 / 地形

- **到处起火**：火会在拿盘子前、拿菜前、切菜前等位置随机出现，需持续灭火（来源：bilibili 3-2 描述）。
- **烧烤 + 鼓风机**：灭火的同时还要吹鼓风机维持烧烤炉火，否则串烤不熟。
- 水枪承担灭火和洗盘双重任务。

## 打法与分工（2P）

- P1（队友）：切料 + 串串 + 烧烤 + 鼓风机。
- P2（你 / AI）：专职灭火 + 洗盘 + 接熟串出餐。
- 流程：AI 优先清火（挡路/挡设备位置的火），火清完再处理盘子和出餐；队友稳住烧烤不断料。

## 陷阱与注意

- 火不灭会挡路、烧糊食材、甚至烧掉成品，优先级最高。
- 灭火和洗盘共用水枪，AI 要判断优先级：挡路火 > 洗盘 > 出餐（出餐可让队友代接）。
