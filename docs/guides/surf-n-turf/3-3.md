> 松饼关：要按按钮开机关，站位不当会掉下去。搅拌碗放中间、料直接投进碗里是提速关键。

## 菜谱 / 订单

- 松饼（煎饼）：面粉 + 鸡蛋 → 搅拌 → 倒进煎锅煎熟；巧克力松饼加切好的巧克力，草莓松饼加切好的草莓（待核实具体类型）。
- 工序：料投进搅拌碗 → 搅拌 → 倒进锅 → 煎熟装盘。无蜂蜜（有蜂蜜的是蛋糕，别搞混）。

## 关卡机制 / 地形

- **按钮机关**：需按按钮开启设备/通道，注意别掉下去（来源：bilibili 3-3 描述）。
- **搅拌碗 + 锅**：搅拌碗放中间更方便投料；锅子可先放中间，碗搅好直接倒进锅。
- 菜单前四单每轮相同，可背下来抢开局。

## 打法与分工（2P）

- 玩家：按按钮、取料投碗（左边每次拿两份，右边可拿 3~4 份）。
- 你：守搅拌碗和煎锅，接料搅拌 → 倒锅 → 煎熟装盘出餐，记得拿盘子。
- 流程：开局先按两边按钮；搅拌碗放中间，两侧直接往右投进碗；锅放中间接碗料；本关至少完成 6 单。

## 陷阱与注意

- 掉下去 = 长时间离场，走位宁慢勿险；按钮和投掷路线都要避开坑。
- 松饼和蛋糕原料几乎一样，区别是「无蜂蜜上煎锅」；倒进烤箱会直接变垃圾。
