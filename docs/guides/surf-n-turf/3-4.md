## 关卡机制 / 地形

- **海浪**：周期性海浪会卷走台面/工作区上的成品，白做的菜会被冲走（来源：bilibili 3-4 描述）。
- 三次海浪时间参考（剩余时间）：**4:55、3:25、1:55**（来源：bilibili「全都好吃」3-4 描述，实际以实机为准）。
- 浪前必须把做好的菜送出去或收进安全位置。

## 打法与分工（2P）

- P1（队友）：负责主菜流水线（切/搅/烤），浪前把手头成品投给 P2。
- P2（你 / AI）：盯着出餐与海浪倒计时，浪来前把成品送餐；浪过再补料。
- 流程：按海浪节奏切分「做菜窗口」和「出餐窗口」；每波浪前清空台面，浪后立刻重新铺料。

## 陷阱与注意

- 记错浪时间是最大陷阱：成品被卷走等于整段白做，四星门槛高（1300），基本要按浪点重开。
- 浪前手头半成品也别留在会被冲走的位置；能用盘子/汉堡胚兜住的料优先兜住。
