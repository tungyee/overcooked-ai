## 菜品

`Sushi_Fish`（`["Seaweed", "BoiledSushiRice", "SushiFish"]`）——海苔 + 熟寿司饭 + 切好的鱼，完整寿司卷。

## 箱子产出（crate）

| 位置 | 产出 | 处理 |
|---|---|---|
| `K(-2, 0)` | SushiRice 寿司米 | 煮熟（cook） |
| `K(-1, 0)` | SushiFish 鱼 | 切（chop_stages 8） |
| `K( 0, 0)` | Seaweed 海苔 | 直接取 |

## 盘堆（干净盘）

4 个柜台各有一叠：`(-1,3)`, `(0,3)`, `(3,-4)`, `(-1,-4)`。

## 布局要点

- **P1 出生 `(-4,1)`（左侧），P2 出生 `(2,-1)`（右侧）**。
- 顶部 `gz=3` 一排 = 加工区：3 个砧板 `H`（中间）+ 出餐口 `O`/盘回收 `R`（右上）+ 柜台。
- 底部 `gz=-4` 一排 = 煮饭区：3 个灶台 `C`（中间）+ 垃圾桶 `B` + 柜台。
- 箱子 `K` 全在中线 `gz=0`（米饭/鱼/海苔各一），两侧开敞、无隔断，取料路径短。
- 出餐口 `O` **寻路占地 2 格（横）**：`(2,3)(3,3)`；交互格单格 `(2,3)`。
- 底部 `gz=-5` 以下是墙（不可走）；无底部通道，左右半区只能从上、中、下三排直穿。
