## 菜品

- `Sushi_Cucumber`（`["Seaweed", "BoiledSushiRice", "Cucumber"]`）——海苔 + 熟寿司饭 + 切好的黄瓜。
- `Sushi_PlainPrawn`（`["SushiPrawn"]`）——虾切好直接装盘。

## 箱子产出（crate）

| 位置 | 产出 | 处理 |
|---|---|---|
| `K(-6,-2)` | Seaweed 海苔 | 直接取 |
| `K(-6,-1)` | SushiPrawn 虾 | 切（chop_stages 8） |
| `K(-6, 0)` | SushiRice 寿司米 | 煮熟（cook） |
| `K( 7, 0)` | Cucumber 黄瓜 | 切（chop_stages 8） |

## 盘堆（干净盘）

落在这些 counter 上：`(-3,-3)`, `(-3,-1)`, `(7,1)`, `(7,-2)`。

## 布局要点

- **P1 出生 `(-2,0)`（左侧），P2 出生 `(5,0)`（右侧）**。
- 左侧 = 切菜区：3 个砧板 `H`（gz=2）+ 3 个箱子（海苔/虾/米饭）+ 出餐口 `O`。
- 右侧 = 煮饭区：3 个灶台 `C`（gz=3）+ 箱子（黄瓜）+ 洗碗池 `W` + 晾干架 `D` + 盘回收 `R`。
- 中间 `gx=0` 列（gz -3..2，6 格柜台 `X`）= 左右两区之间的**中转台**。
- 底部 `gz=-5` 是左右两半互通的**底部通道**（可从任一区绕行）；`gz=-6` 是墙（不可走）。
- 出餐口 `O` **寻路占地 2 格（竖）**：`(-6,-3)(-6,-4)`；交互格单格 `(-6,-4)`。
- **食材与加工站交叉**：米饭/虾在左箱、灶台在右；黄瓜在右箱、砧板在左 → 生料必须跨区运输，天然需要中间中转台交接。
