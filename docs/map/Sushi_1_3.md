## 图例

| 符号 | 含义 |
|---|---|
| `#` | 不可走（墙 / 障碍） |
| `.` | 可走地板 |
| `H` | 砧板（chopping） |
| `C` | 灶台（cooking） |
| `K` | 箱子（crate） |
| `W` | 洗碗池（washing） |
| `B` | 垃圾桶（bin） |
| `R` | 盘子回收 / 晾干架（plate_return） |
| `O` | 出餐口（plate_station） |
| `X` | 柜台（counter） |
| `1` | Player 1 出生位 |
| `2` | Player 2 出生位 |

## 箱子产出（crate）

| 位置 | 产出 |
|---|---|
| `K(-6,-2)` | Seaweed 海苔 |
| `K(-6,-1)` | SushiPrawn 虾 |
| `K(-6, 0)` | SushiRice 米饭 |
| `K( 7, 0)` | Cucumber 黄瓜 |

## 盘堆（干净盘）

落在这些 counter 上：`(-3,-3)`, `(-3,-1)`, `(7,1)`, `(7,-2)`。

## 布局要点

- **P1 出生 `(-2,0)`（左侧），P2 出生 `(5,0)`（右侧）**。
- 左侧 = 切菜区：3 个砧板 `H`（gz=2）+ 3 个箱子（海苔/虾/米饭）+ 出餐口 `O`。
- 右侧 = 煮饭区：3 个灶台 `C`（gz=3）+ 箱子（黄瓜）+ 洗碗池 `W` + 回收 `R`。
- 中间 `gx=0` 列（gz -3..2，6 格柜台 `X`）= 左右两区之间的**中转台**。
- **食材与加工站交叉**：米饭/虾在左箱、灶台在右；黄瓜在右箱、砧板在左 → 生料必须跨区运输，天然需要中间中转台交接。
