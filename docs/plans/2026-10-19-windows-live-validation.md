# Windows 本机集成与限时实测

目标：把最新主线修复版接入本机游戏，实际验证行为树，记录成功/失败/等待而非据离线测试声称效果。

1. 保留旧 Windows 目录，备份最新修复源码。复用已验证的扫描码/完整性级别实现，移入 ai/output；保留上游 macOS 后端，Windows 禁止右 Alt 冲刺。加入失焦、协议未就绪、厨师缺失守卫。
2. run_agent / Agent.run 支持 --seconds、--stop-file 和退出 finally 松键/断开；启动器自动检测 UIPI、必要时 UAC 提升，同目录锁防双开；建立独立 .venv。
3. 编译新版上游 terrain/grids 插件，使用新版本标识，备份旧 DLL 后部署。默认关闭昂贵 Discover，网络发送不能锁住主线程；无客户端不进行完整采集。保持新协议。
4. 测试 Windows 适配、限时/失焦守卫以及全量行为树回归。退出状态才部署，随后通过日志/端口核对实际加载版本。
5. 用户进入分割键盘双人 1-5 后，先只读检查新协议和可达性，再启动 150 秒 AI，观察并保留 trace。测试期间仅控制 P2，达到时限/异常/停止均释放本进程按键。必要时根据真实失败修 Python 并短测；替换 DLL 才需要重启。
6. 交付实测报告：关卡、时长、有效决策/输入、任务结果、失败/等待原因、分数差和可归因范围。没有出餐或仍卡住必须直说，不将人类出餐全部归功于 AI。

沿用 Code / brainstorming 流程；用户已明确要求实际运行，直接集成、部署和限时控制，不再请求同一操作授权。

执行结果：步骤 1–6 已完成。150 秒实控结束，11 成功终态 / 19 失败终态，全队新增 4 份出餐；实测后补持盘归属和 trace 修正，追加修正尚未再次实控。详细证据、局限和性能数据见 notes 报告。
